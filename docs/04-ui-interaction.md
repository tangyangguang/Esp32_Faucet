# UI 与交互草案

## 当前已确认原则

- 本地输入使用四个功能按键：`CANCEL`、`OK`、`PLUS`、`MINUS`，面板标注建议使用“取消 / 确认 / 加 / 减”。
- 不使用颜色命名按键。
- 本地交互优先支持高频操作和软件停止兜底。
- 复杂配置优先放到 Web，避免本地菜单过重。

## 按键语义

- `CANCEL`：取消、返回；出水中按下立即停止并关阀。
- `OK`：确认、启动、暂停/继续。
- `PLUS`：待机选择下一个预设；确认/暂停页增加本次目标水量。
- `MINUS`：待机选择上一个预设；确认/暂停页减少本次目标水量。
- `OK` 长按：在确认/暂停页切换调整步进，默认 0.5L，切换后为 0.1L，再长按切回 0.5L。

## 状态交互

### 待机

- `PLUS` 短按：切换到下一个启用预设。
- `MINUS` 短按：切换到上一个启用预设。
- `OK` 短按：进入当前预设的二次确认。
- `CANCEL` 短按：确保关阀并保持待机，不记录出水日志。

### 二次确认

- `OK` 短按：开始出水。
- `CANCEL` 短按：取消并返回待机。
- `PLUS` / `MINUS` 短按：调整本次目标水量，不修改预设。
- `OK` 长按：切换本次调整步进 0.5L / 0.1L。
- 10 秒无操作：自动取消。

### 出水中

- `CANCEL` 按下瞬间：立即关阀，返回待机或错误提示，优先级最高。
- `OK` 短按：暂停。
- `PLUS` / `MINUS` 短按：无动作，避免运行中误改目标。

### 暂停

- `OK` 短按：继续出水。
- `CANCEL` 短按：停止任务并进入结果显示。
- `PLUS` / `MINUS` 短按：调整本次总目标水量，最小不低于已出水量。
- `OK` 长按：切换调整步进 0.5L / 0.1L。
- 超过暂停超时时间：自动停止并记录暂停超时。

### 结果显示

- 正常完成、用户停止、暂停超时、安全停止或流量异常后显示本次结果，默认 15 秒，Web 可配置 0-60 秒，0 表示不显示。
- `OK` 或 `CANCEL`：立即回到待机。
- `PLUS` / `MINUS`：立即回到待机并切换预设。

### 本地菜单边界

当前固件不实现通用多级本地菜单；本地只保留常用出水、暂停/继续、停止和本次目标水量调整。预设、滤芯、WiFi、OTA、校准参数、恢复出厂等复杂操作放 Web 或 Esp32Base 系统页面。

## LCD1602 页面草案

| 页面 | 第一行 | 第二行 |
| --- | --- | --- |
| 待机 | `P2 7.50L` | `+/- Sel OK` |
| 确认/调整 | `Set 7.50L S0.50` | `+/- Adj OK Go` |
| 运行 | `Lft 4.20L 01:28` | `Out 3.30L OK` |
| 暂停 | `Paus 3.30/7.50` | `Step0.50 +/-OK` |
| 完成 | `Done 7.50L` | `02:43` |
| 用户停止 | `Stopped 3.30L` | `01:28` |
| 错误 | `Flow Error 3.30L` | `01:28` |

LCD1602 只有 16 字符宽，文案优先使用短英文、数字和固定缩写，避免中文过宽和频繁换页。

## Web 页面草案

- 首页：卡片式显示当前状态、当前预设、基础统计和启用滤芯寿命进度。
- 配置：阈值、蜂鸣器、显示、安全参数。
- 预设：9 组预设的启用、名称、类型和值；名称最多 15 个字符。
- 日志：分页查询，支持首页、上一页、下一页和每页条数下拉；每页条数可选 20、30、50、100、200，默认 20。
- 统计：今日、本周、本月、总累计。
- 滤芯：最多 6 个滤芯的已用天数、已用流量、寿命范围、状态、独立设置入口和重置入口。
- 校准：通过 Web 按“设定出水量 / 量杯实际水量”换算并保存流量系数，也可手动保存每升信号数和最多 4 个候选容量；不允许远程启动校准出水，当前本地四键也不进入校准向导。
- OTA：使用 Esp32Base 内置页面。

Web 页面不得提供启动出水、暂停出水、继续出水或停止出水入口。

### Web 滤芯交互

- 滤芯页只显示列表，便于快速查看每级滤芯状态、已用天数、已用流量和寿命设置。
- 每级滤芯提供“设置”入口，进入独立编辑页后再修改启用状态、名称、建议更换周期、最长使用周期、寿命流量、上次更换日期。
- 寿命周期以月输入，按 30 天/月保存；建议更换周期用于“建议更换”，最长使用周期用于“已超期”。
- 寿命流量以 ml 输入，并在输入框下方显示 L，页面展示默认使用 L 且保留 2 位小数。
- 上次更换日期使用浏览器日期选择控件，提交值仍按 `YYYY-MM-DD` 校验；有效日期范围为 2020-2099，保存后作为已用天数的起点。
- 保存或取消后返回滤芯列表页，避免低频配置表单占用列表页空间。
- 重置需要二次确认，提交后清零该级滤芯累计流量、更新更换时间，并返回滤芯列表页。

## 已确认事项

- 本地只允许调整本次出水目标，不修改当前预设配置。
- 出水中 `OK` 短按用于暂停，`CANCEL` 用于停止。
- Web 端不允许任何出水控制。

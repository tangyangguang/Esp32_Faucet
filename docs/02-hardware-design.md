# 硬件设计草案

## 当前已确认原则

- 主控目标为 ESP32-WROOM-32 4MB。
- 输入设备由旧方案的 EC11 改为三个独立功能按键，命名为 `STOP`、`OK`、`NEXT`。
- 硬件设计优先服务安全关阀、日常盲操作、稳定运行和易维护。
- 电磁阀必须为常闭型，软件失效或断电时默认关水。
- 外部电源开关作为硬件停止手段，不属于软件控制范围。

## 硬件范围草案

| 模块 | 策略 |
| --- | --- |
| 主控 | ESP32-WROOM-32 4MB |
| 电磁阀 | 12V 常闭电磁阀，MOS 控制，支持全压吸合 + PWM 保持 |
| 流量计 | YF-S201 霍尔流量计，中断计数 |
| OLED | 0.91 寸 I2C OLED 128x32 |
| 按键 | `STOP`、`OK`、`NEXT` 三个独立按键，低电平有效，按 GPIO 能力配置外部或内部上拉 |
| 蜂鸣器 | 5V 无源蜂鸣器，PWM 控制，可 Web 开关 |
| RTC | DS3231 自动检测支持；未焊接时软件降级 |
| 漏水检测 | 不做 |

## GPIO 草案

| GPIO | 功能 | 说明 |
| --- | --- | --- |
| GPIO16 | 电磁阀控制 | 输出，避开 ADC2，支持 PWM |
| GPIO32 | 流量计脉冲 | 输入中断，WiFi 可用 |
| GPIO36 | `STOP` | 输入中断，最高优先级软件停止关阀 |
| GPIO33 | `OK` | 输入，确认/启动/暂停继续 |
| GPIO35 | `NEXT` | 输入，切换预设/菜单项，必须外部上拉 |
| GPIO17 | 蜂鸣器 PWM | 输出 |
| GPIO21 | I2C SDA | OLED 和 DS3231 自动检测 |
| GPIO22 | I2C SCL | OLED 和 DS3231 自动检测 |
| GPIO1 | UART0 TX | 调试串口 |
| GPIO3 | UART0 RX | 调试串口 |

旧 EC11 释放的 GPIO34、GPIO39 暂不使用，保持未分配，避免把硬件一次性塞满。

## 安全与可靠性要求

- `STOP` 使用可中断输入，按下瞬间触发软件停止关阀路径。
- 外部硬断电开关只作为硬件电源开关事实存在，软件不检测、不控制、不建模。
- 电磁阀驱动必须有续流二极管，MOS 选型留足电流余量。
- 流量计输入需要硬件上拉和基础滤波，软件再做脉冲间隔过滤。
- 强电、12V 执行器和 3.3V 控制信号布线保持隔离和单点共地。
- 未使用接口不参与软件逻辑，避免影响稳定性。

## 已确认实现决策

- `NEXT` 使用 GPIO35。
- `STOP`、`OK`、`NEXT` 三个按键均按外部 10K 上拉设计，低电平有效。
- GPIO34-39 无内部上拉能力，使用这类输入脚时不得依赖内部上拉。

## 旧文档迁移说明

- `old-docs/DOC-02_硬件设计说明.md` 是硬件参考材料。
- 旧文档中的 EC11 引脚和操作设计不迁移。
- 旧文档中的 GPIO 分配需要结合三键方案重新审核。
- 旧文档中的电磁阀、流量计、OLED、蜂鸣器和供电设计可作为硬件基础。

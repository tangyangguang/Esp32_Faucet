# 测试计划

## 当前已确认原则

- 先做 native 可测逻辑，再做上板集成验证。
- 测试计划需要覆盖安全关阀、流量精度、断网本地运行、Web 操作不影响控水等核心风险。
- 测试范围随实现范围收敛，不为不做的功能编写测试。

## Native 测试

- 四键输入：短按、长按、消抖、`CANCEL` 按下即停、运行中 `PLUS`/`MINUS` 无效。
- 状态机：待机、确认、运行、暂停、错误、恢复待机。
- 安全兜底：最大时间、最大出水量、超预设百分比、无流量、异常流量。
- 流量计算：脉冲计数、过滤、启动脉冲数、启动水量和稳态 P/L 分段公式。
- 长期运行：`millis()` / `micros()` 回绕后的超时、流量、电磁阀、显示和蜂鸣器行为。
- 本次目标调整：只在确认页按 Web 配置步进调整，容量默认 0.10L、时间默认 10s，暂停页不允许调整，且不修改预设配置。
- 结果显示：完成、停止和异常后按配置时间显示本次结果。
- 电磁阀：全压吸合、PWM 保持、关阀幂等。
- 配置：默认值、钳位、非当前版本加载默认值、显式保存写入当前结构。
- 传感器算法：50K B3950 NTC + 51K 上拉关键温度点、100K/10K VIN 分压、TDS 10K/15K 分压还原、TDS 公式、25C 温度回退和校准点拟合。
- ADC 抽象：ADS1115 AIN0-AIN3 映射、PGA 量程、溢出处理、TDS 自动升降量程、切换后丢弃首个样本。
- 传感器管理：1s 采样、连续失败/恢复标志、出水期间水温/TDS 最后滑动窗口值和有效采样数聚合。
- 记录：追加、分页、容量滚动，并保存目标值、有效脉冲数、最小间隔过滤数、当时启用的计量方案 ID、水温/TDS 最后窗口摘要和传感器状态；校准实测容量只保存在校准会话样本中。
- 统计：今日、本周、本月、总累计更新，并按记录窗口样本数聚合水温/TDS 趋势；默认排除未校准或异常传感器数据。
- 滤芯：最多 6 个滤芯，出水完成后累计流量，重置后重新计算天数和流量。
- Web 边界：路由表和页面中不存在启动出水、暂停出水、继续出水、停止出水入口。
- Web API：状态、预设、记录、统计、滤芯和校准相关接口返回小 JSON 或轻量 HTML 片段；计量方案、预设、滤芯修改和校准动作只接受 POST，并执行同源 POST 校验。手工设置计量参数必须创建新当前参数记录；出水确认、运行、暂停期间必须拒绝，校准会话等待本地出水、等待实测容量或已生成待应用期间允许保存手工参数。
- Web 传感器：状态 JSON 包含输入电压、水温、TDS、电压、校准状态和故障标志；配置 JSON 包含传感器开关；TDS 校准 POST 在确认/运行/暂停期间必须拒绝。
- 本地屏：TFT 待机、确认、运行、暂停、结果、报警和校准页面显示正确；待机页展示水温/TDS 摘要，确认、运行、暂停、结果、报警和校准页不得被传感器信息打断核心操作提示。

## 上板测试

- GPIO：四个按键、电磁阀 PWM/SD、主/备用流量输入、GPIO13 蜂鸣器飞线、SPI ST7789 TFT。
- ADS1115：确认地址 `0x48`、AIN1 水温和 AIN2 TDS 电压读数；ADC 不存在、两路未接或异常时设备仍可本地出水和停止。
- 水温：用万用表确认 MH-01 绿色温度线到黑色 GND 室温约 40K-70K；接入 51K 上拉分压后与温度计对比，必要时只调温度偏移。
- TDS：TDS Board V1.0 使用 PCB 5V 接口，AO 经 10K/15K 分压进入 ADS1115 AIN2；先对照万用表确认页面电压已还原为模块 AO 电压，再用水样验证趋势并校准。
- 新设备无配置版本键时，从系统设置保存阀门全功率时间、保持占空比和无流量超时；确认运行时按保存值切换 PWM，并在保存的超时点而非默认值停止。
- 输入电压：当前先不启用 ADS1115 AIN0 VIN 诊断；待前三路硬件验证稳定后单独验证。
- 网络：WiFi 配网、mDNS hostname、Web Basic Auth、OTA 入口。
- 本地操作：选择 7.5L 预设，调整到 5L/9L，运行中暂停、继续和停止。
- 断网：WiFi 断开时本地启动、暂停、停止正常。
- 异常：拔掉流量计、关闭水源、模拟超时。
- 休眠：TFT 背光熄灭和按键唤醒。

## 验收标准

- `CANCEL` 软件停止响应不超过 50ms。
- 自动关阀动作不超过 100ms。
- 校准后定量误差不超过 ±3%。
- 水温在 10-30C 自来水常见区间内，对照温度计校正后应达到工程可用的一致性；未校正前允许显示“未校准/仅供参考”。
- TDS 能稳定区分净水 5-10ppm、滤芯衰减 10-20ppm、自来水约 160ppm、井水约 300-600ppm；低值区间优先使用较小 ADC 量程采样。
- TDS 未校准时可以显示和记录，但 Web 和记录详情必须明确标记未校准；保存校准只写一次系统配置，不按采样周期写 Flash。
- 本地结果页 `OK` 长按不得进入校准录入；校准录入、样本删除和参数应用只在 Web 完成。
- Web 校准样本必须来自本地校准会话中有脉冲明细且结束状态可校准的记录；录入实测水量只更新会话样本和轻量摘要，保存推荐参数时才创建新的当前计量参数；偏差过大在计量参数生成阶段拒绝或告警。
- Web 记录页不固定展示过滤脉冲列；校准实测容量只在校准会话样本中显示，记录页不显示“已校准”或记录级实测水量。
- 本地暂停、继续、停止和本次目标调整必须能脱离 Web 完成。
- Web 端不得存在任何出水控制入口或 API。
- Web 首页允许切换“下次预设”；切换不得打开阀门、启动出水、改变已确认/正在运行任务的 active preset 或本次目标值。
- 断网不影响本地出水。
- 出水确认、运行和暂停期间，Web 只读业务页面允许打开，但不得触发远程控水；记录查询、统计查询、校准会话样本录入/放弃和滤芯重置必须返回轻量 busy，不得执行文件扫描、样本聚合、大 JSON 输出或文件写入；Web 压测下 `maxBaseHandleUs` 和 `maxLoopIntervalUs` 必须支撑 `CANCEL <50ms`。
- Web API 路径不得出现 `/water/`、`/start`、`/stop` 这类远程出水控制语义。
- 重启后默认不继续未完成出水任务。
- 出水过程中所有异常优先关阀。
- 本地菜单不得修改预设值。
- 日志容量以当前分区下固定 15,000 条为工程边界；验证重点是空间不足前正常写入、达到工程容量后按环形记录覆盖最旧记录。
- 滤芯查看支持最多 6 个滤芯，显示已用天数和已用流量。

## 已确认测试策略

- 长期运行测试做 72 小时连续运行。
- Native 测试使用 PlatformIO native 环境，业务核心保持纯 C++ 可测，硬件访问通过桩替代。
- Web 写操作 busy 策略已有平台无关 native 行为测试，并已用 Esp32Base native Web handler harness 直接执行关键 handler，覆盖认证、同源、异常参数、busy 重定向、状态码、headers 和无副作用边界。
- 后续新增高风险 Web 写 handler 时，优先补充行为测试；不使用读取生产源码字符串的测试来约束实现形状。

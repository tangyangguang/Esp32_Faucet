# 计量方案时间估算参数设计

## 背景

当前流量计计量方案使用 3 个参数根据有效脉冲估算实际出水容量：

- `startupPulseCount`
- `startupVolumeMl`
- `stablePulsePerLiter`

这能解决“多少脉冲对应多少水”，但不能直接解决“给定目标容量预计要多久”或“给定出水时间预计是多少容量”。预设和确认页需要这类预计信息，尤其是容量预设需要给用户一个预计出水时长。

## 目标

把流量计计量方案扩展为 5 个计量参数，并按用途分成两组：

- 容量估算计量参数：根据流量计脉冲估算实际出水容量。
- 时间估算计量参数：根据目标容量估算预计出水时间和预计稳态流速。

新增时间估算参数只用于预计展示，不参与实际出水容量结算。

## 参数模型

每套流量计计量方案保存 5 个计量参数：

```text
容量估算计量参数：
  startupPulseCount
  startupVolumeMl
  stablePulsePerLiter

时间估算计量参数：
  startupDurationMs
  stableFlowMlPerMin
```

`startupDurationMs` 表示启动段预计时长。`stableFlowMlPerMin` 表示进入稳态后的预计流速，单位 ml/min。

系统内置默认方案使用：

```text
startupPulseCount = 8
startupVolumeMl = 130
stablePulsePerLiter = 248
startupDurationMs = 5000
stableFlowMlPerMin = 1950
```

## 运行边界

实际容量始终只由容量估算计量参数按有效脉冲计算，包括：

- 出水记录容量。
- 滤芯累计容量。
- 统计累计容量。
- 容量模式停止判断。
- 时间模式结束后的容量记录。

时间估算计量参数只用于预计展示，包括：

- 容量预设的预计出水时间。
- 确认页的预计出水时间。
- 预设或确认页显示的预计稳态流速。
- 给定时间时的预计容量辅助显示。

异常出水不能用时间估算补容量。0 脉冲不能假设真的有出水；流量异常仍应按异常处理并停止出水。

## 估算公式

设：

```text
V  = 目标容量或预计容量，单位 ml
T  = 预计时间，单位 ms
Vs = startupVolumeMl
Ts = startupDurationMs
Fs = stableFlowMlPerMin
```

目标容量预计时间：

```text
Ts = 0 或 Vs = 0:
  T = V * 60000 / Fs

V <= Vs:
  T = V * Ts / Vs

V > Vs:
  T = Ts + (V - Vs) * 60000 / Fs
```

给定时间预计容量：

```text
Ts = 0 或 Vs = 0:
  V = T * Fs / 60000

T <= Ts:
  V = T * Vs / Ts

T > Ts:
  V = Vs + (T - Ts) * Fs / 60000
```

这些公式只用于预计，不改变实际容量计量公式。

## 流速概念

页面和文档必须区分 3 种流速：

- 实时流速：出水过程中用最近脉冲时间窗口计算，用于运行页实时显示和流量异常判断。
- 预计流速：计量方案中的 `stableFlowMlPerMin`，更准确称为预计稳态流速，用于预设和确认页展示。
- 平均流速：出水结束后用实际记录容量除以实际出水时长计算，用于历史记录和统计展示。

## 生成与编辑

计量方案生成结果必须同时生成 5 个参数。不能只生成容量估算计量参数，否则方案缺少时间估算内容。

手工新建和修改计量方案时允许编辑 5 个参数。页面必须分组展示，避免用户误以为 5 个参数都参与同一个公式。

修改任一计量参数都会影响方案修订号。历史记录追溯方案已被 `2026-06-11-flash-storage-consolidation-design.md` 覆盖：新出水记录只保存计量方案 ID，不再保存完整计量参数快照。

## 持久化与迁移

历史出水记录保存规则以 `2026-06-11-flash-storage-consolidation-design.md` 为准：新记录保存当时计量方案 ID，不保存 5 个计量参数快照。

旧配置迁移时，已有 3 个容量估算计量参数按原规则迁移；新增时间估算计量参数填入默认值：

```text
startupDurationMs = 5000
stableFlowMlPerMin = 1950
```

迁移说明中应标明时间估算计量参数来自迁移默认值，不是样本生成。

`stableFlowMlPerMin` 的有效范围为 `50-30000 ml/min`。`startupDurationMs` 的有效范围为 `0-60000 ms`。`startupDurationMs = 0` 表示无启动时间段，预计时间全部按稳态流速计算。`stableFlowMlPerMin` 必须大于 0。

## 页面要求

校准页、计量方案编辑页和计量方案列表必须明确分组：

```text
容量估算计量参数：启动脉冲数、启动水量、稳态 P/L
时间估算计量参数：启动时长、预计稳态流速
```

页面需要明确提示：

```text
时间估算计量参数只用于预计时间和预计流速展示，不参与实际出水容量、滤芯累计或统计累计。
```

LCD 确认页可以在空间允许时显示容量预设预计时间、时间预设预计容量。Web 预设和确认相关页面应显示对应预计值，但不得提供任何远程出水控制能力。

## 测试关注点

- 5 个计量参数的默认值、有效范围和迁移结果。
- 目标容量预计时间公式，包括无启动段、小于启动水量、大于启动水量。
- 给定时间预计容量公式，包括无启动段、启动段内、稳态段。
- 实际容量、滤芯累计和统计累计不使用时间估算参数。
- 异常或 0 脉冲出水不使用时间估算补容量。
- 计量方案生成、保存、编辑和历史快照都包含 5 个参数。

# UI 与交互

## 当前已确认原则

- 本地输入使用四个功能按键：`CANCEL`、`OK`、`PLUS`、`MINUS`，面板标注建议使用“取消 / 确认 / 加 / 减”。
- 不使用颜色命名按键。
- 本地交互优先支持高频操作和软件停止兜底。
- 复杂配置优先放到 Web，避免本地菜单过重。

## 按键语义

- `CANCEL`：取消、返回；出水中按下立即停止并关阀。
- `OK`：确认、启动、暂停/继续；校准出水中无暂停/继续。
- `PLUS`：待机选择下一个预设；确认页按 Web 配置步进增加本次目标值。
- `MINUS`：待机选择上一个预设；确认页按 Web 配置步进减少本次目标值。
- `OK` 长按：确认页、暂停页和结果页不触发额外功能。

## 状态交互

### 待机

- `PLUS` 短按：切换到下一个启用预设。
- `MINUS` 短按：切换到上一个启用预设。
- `OK` 短按：进入当前预设的二次确认。
- `CANCEL` 短按：确保关阀并保持待机，不记录出水记录。

### 二次确认

- `OK` 短按：开始出水。
- `CANCEL` 短按：取消并返回待机。
- `PLUS` / `MINUS` 短按：调整本次目标值，不修改预设；容量默认步进 0.10L，时间默认步进 10s，步进值可在 Web 后台配置。
- 60 秒无操作：自动取消，默认值与产品需求和固件配置一致。

### 出水中

- `CANCEL` 按下瞬间：立即关阀，返回待机或错误提示，优先级最高。
- `OK` 短按：暂停。
- `PLUS` / `MINUS` 短按：无动作，避免运行中误改目标。

### 暂停

- `OK` 短按：继续出水。
- `CANCEL` 短按：停止任务并进入结果显示。
- `PLUS` / `MINUS` 短按：无动作，避免暂停后误改容量或时间目标。
- 超过暂停超时时间：自动停止并记录暂停超时。

### 结果显示

- 正常完成、用户停止、暂停超时、安全停止或流量异常后显示本次结果，默认 30 秒，Web 可配置，0 表示不显示。
- `OK` 或 `CANCEL`：立即回到待机。
- `PLUS` / `MINUS`：立即回到待机并切换预设。
- 结果页不提供本地校准录入；流量校准统一从 Web 校准流程进入。

### 本地校准会话

- 入口：流量计校准流程从 Web 进入；网页进入只改变校准状态，不远程启动出水。
- 出水和停水：只允许在设备旁通过本地按键完成，网页不提供启动、暂停、继续或停止出水入口。
- 本地职责只限校准出水动作：`OK` 开始校准出水，`CANCEL` 停止校准出水；本地不输入实测容量、不删除样本、不保存或应用参数。
- 校准出水不使用当前预设目标，不按预设容量或预设时长自动结束；只受最大出水时长、最大出水量、无流量超时、高流量保护和本地停止限制。
- 每次校准出水结束后，设备进入等待实测容量状态；用户必须在网页输入量杯读数。
- 当前会话至少 2 条有效样本后自动刷新推荐计量参数；最多保留 6 条有效样本和 6 次尝试。用户不需要手动点击“生成参数”。
- 若量杯溢出、读数不清、水路未打开、暂停后恢复或本次出水不是典型单段过程，用户可以在等待录入时放弃本次样本；放弃后它只作为本次会话记录保留，不参与自动结果。
- 中途暂停后恢复的样本不能参与生成。校准会话中已暂停恢复、明细截断、无有效脉冲或没有实测容量的样本都必须标记为无效。
- 自动生成的结果由用户确认应用后成为最新当前参数；用户也可以在 Web 手工设置当前参数。历史参数不提供恢复、原地编辑或删除入口；复制历史参数只用于预填手工设置表单，保存后创建新参数 ID。

### 本地菜单边界

当前固件不实现通用多级本地菜单；本地只保留常用出水、暂停/继续、停止和确认页本次目标值调整。预设、滤芯、WiFi、OTA、校准参数、恢复出厂等复杂操作放 Web 或 Esp32Base 系统页面。

## 本地显示页面

当前本地显示使用 240x240 ST7789 TFT。页面以大号主数值、状态标签、进度条、指标卡和底部按键提示组织，不再保留 16x2 文本约束。

## TFT 页面

| 页面 | 主信息 | 辅助信息 |
| --- | --- | --- |
| 待机容量 | 当前预设容量和预设编号 | 今日累计、水温、TDS、网络状态 |
| 待机时间 | 当前预设时长和预设编号 | 预计容量、今日累计、水温、TDS |
| 确认容量 | 本次目标容量 | 预计时长、步进值、确认/取消提示 |
| 确认时间 | 本次目标时长 | 预计容量、步进值、确认/取消提示 |
| 运行容量 | 已出水量和目标进度 | 剩余量、实时流速、平均流速、传感器摘要 |
| 运行时间 | 已运行时间和目标进度 | 剩余时间、已出水量、实时流速、传感器摘要 |
| 暂停 | 已出水量和暂停状态 | 继续/停止提示、当前目标和已用时间 |
| 完成 | 本次结果和出水量 | 用时、平均流速、返回提示 |
| 用户停止 | 停止结果和出水量 | 用时、平均流速、返回提示 |
| 报警 | 异常类型 | 已关阀状态、返回提示 |
| 校准待出水 | 校准状态和有效样本数 | 本次会话样本、本地开始提示 |
| 校准出水中 | 已出水量 | 已用时、最大时长剩余倒计时、实时流速、本地停止提示 |
| 校准待录入 | 本次估算出水量 | 用时、网页录入提示 |
| 熄屏 | 背光关闭 | 按键唤醒 |

待机页可以直接显示水温、TDS 和已接入的输入电压摘要；当前原生 ADC 接线阶段只接入水温和 TDS。确认、出水、暂停、结果、报警和校准过程中，传感器信息只能作为辅助指标，不得抢占核心操作提示。`PLUS` / `MINUS` 切换预设、`OK` 进入确认、`CANCEL` 返回待机时，应立即刷新到对应主页面。

## Web 页面

- 首页：卡片式显示当前状态、当前预设、基础统计和启用滤芯寿命进度。
- 配置：阈值、蜂鸣器、显示、安全参数、本地确认页调整步进和传感器开关；水温/TDS 使用枚举选择，不输入内部数字类型。
- 预设：9 组预设的启用、名称、类型和值；名称最多 15 个字符。
- 记录：分页查询，紧凑显示开始时间、目标值、出水量、持续时间、预设模式、结束原因、脉冲/P-L、计量方案和操作。过滤脉冲属于低频诊断信息，只在有值时显示在脉冲单元格小字里；记录页不维护记录级实测量或长期校准样本库。
- 统计：今日、本周、本月、总累计，并展示水温和 TDS 趋势。
- 滤芯：最多 6 个滤芯的启用状态、上次更换日期、已用天数、已用流量、建议/最长/流量寿命详情、状态、独立设置入口和重置入口。
- 校准：顶层只保留“校准”。校准首页直接展开流量计校准、温度校准、水质校准三块；不使用折叠区。温度校准在当前块用摄氏度参考值保存偏移；水质校准使用一次会话内的稳定校准点自动生成参数，不提供单点/多点模式切换入口。
- 流量计校准中心：通过校准首页进入，围绕“当前参数”组织页面。主流程展示当前参数、进入校准模式、本次校准样本、自动推荐结果、手工设置参数入口和历史参数；参数历史只用于查看或复制预填手工设置表单，保存后创建新当前参数；脉冲明细只用于查看当前或最近一次校准会话样本。网页不允许远程启动、暂停、继续或停止出水；实际出水和停水只能通过本地按键执行。网页刷新后必须保留当前校准会话状态，出水停止后应继续显示实测容量录入或样本放弃流程。
- OTA：使用 Esp32Base 内置页面。

Web 页面不得提供启动出水、暂停出水、继续出水或停止出水入口。

### Web 滤芯交互

- 滤芯页只显示列表，便于快速查看每级滤芯状态、上次更换日期、已用天数、已用流量和寿命设置。
- 每级滤芯提供“设置”入口，进入独立编辑页后再修改启用状态、名称、建议更换周期、最长使用周期、寿命流量、上次更换日期。
- 寿命周期以月输入，按 30 天/月保存；建议更换周期用于“建议更换”，最长使用周期用于“已超期”。
- 寿命流量以 ml 输入，并在输入框下方显示 L，页面展示默认使用 L 且保留 2 位小数。
- 上次更换日期使用浏览器日期选择控件，提交值仍按 `YYYY-MM-DD` 校验；有效日期范围为 2020-2099，保存后作为已用天数的起点。
- 保存或取消后返回滤芯列表页，避免低频配置表单占用列表页空间。
- 重置需要二次确认，提交后清零该级滤芯累计流量、更新更换时间，并返回滤芯列表页。

## 已确认事项

- 本地只允许在确认页调整本次出水目标，不修改当前预设配置；暂停页不允许调整目标。
- 出水中 `OK` 短按用于暂停，`CANCEL` 用于停止。
- 校准出水中 `OK` 不暂停、不继续，`CANCEL` 用于停止本次校准出水。
- Web 端不允许任何出水控制。

# 流量计计量方案设计

本文定义“流量计计量方案”的新模型，用于替代旧的固定编号计量配置。本文只描述方案设计，不包含代码实施步骤。

> 2026-06-04 更新：普通校准流程已实现为“校准会话”。校准会话生成合格结果后，用户在校准页“确认应用”会创建并启用一套新计量方案；这是面向普通用户的校准完成动作。专业计量方案页从长期样本库生成方案时，仍保持本文原规则：生成结果先保存为新方案，再由用户显式启用。

## 目标

流量计计量方案用于保存水流量计把脉冲换算成水量时使用的一整套参数。它和具体流量计、水路、水压、滤芯状态、安装环境有关。

系统需要支持多套方案，目的包括：

- 实验时保存多套参数，便于切换对比。
- 长时间启用某套方案后发现效果不好，可以快速切回以前验证过的方案。
- 不同水压、水路或流量计条件下，可以使用不同方案。
- 生成结果后，先查看结果和样本依据，再决定是否保存和启用。

## 命名

页面和文档统一使用以下名称：

- 流量计计量方案：一套可保存、可启用的计量参数。
- 当前计量方案：设备正在用于出水估算的方案。
- 系统内置默认方案：首次启动或默认方案缺失时由系统创建的兜底计量方案。
- 计量方案生成结果：根据样本生成、尚未保存为正式方案的结果。
- 新建计量方案：手工输入名称和 5 个计量参数创建的方案。
- 修改计量方案：修改已有方案的名称和 5 个计量参数。
- 可用方案：可以被选择启用的方案。
- 停用方案：保留历史追溯，但不出现在日常启用选择中的方案。

不再使用固定位置编号作为用户概念。

## 计量参数

每套方案保存 5 个计量参数，按用途分为两组。

容量估算计量参数用于根据有效脉冲估算实际出水容量：

- 启动脉冲数 `Ns`
- 启动水量 `Vs`
- 稳态 P/L `Ps`

容量估算公式保持不变：

```text
P = 0:
  V = 0

0 < P <= Ns:
  V = round(P * Vs / Ns)

P > Ns:
  V = Vs + round((P - Ns) * 1000 / Ps)
```

`Ns = 0` 且 `Vs = 0` 时，启动段等价于没有，全部有效脉冲按稳态 P/L 计算。

时间估算计量参数用于根据目标容量估算预计出水时间和预计稳态流速：

- 启动时长 `Ts`，单位 ms。
- 预计稳态流速 `Fs`，单位 ml/min。

时间估算参数只用于预设、确认页等位置的预计展示，不参与实际出水容量、滤芯累计或统计累计。任何实际容量都必须由容量估算计量参数按有效脉冲计算；异常出水或 0 脉冲不能用时间估算补容量。

目标容量预计时间：

```text
Ts = 0 或 Vs = 0:
  T = V * 60000 / Fs

V <= Vs:
  T = V * Ts / Vs

V > Vs:
  T = Ts + (V - Vs) * 60000 / Fs
```

给定时间预计容量：

```text
Ts = 0 或 Vs = 0:
  V = T * Fs / 60000

T <= Ts:
  V = T * Vs / Ts

T > Ts:
  V = Vs + (T - Ts) * Fs / 60000
```

## 方案数量与状态

业务上不设置固定的方案数量上限。页面不能把某个固定数量作为用户规则，也不能显示固定空位。

方案列表按动态数据展示。默认显示当前方案和可用方案；停用方案默认折叠或通过筛选查看。

底层实现可以有工程容量边界，用于保护 Flash、RAM 和页面响应时间。但这个边界不是产品概念。达到工程容量时，只允许用户删除未使用过的方案，或提示需要清理未使用方案。

每套方案有状态：

- 可用：可以被启用，也可以修改。
- 停用：不能直接作为启用选择，仍可查看、修改和恢复为可用。

当前计量方案必须始终是可用方案。

系统必须始终至少有一套可用且启用中的当前计量方案。当前计量方案不能停用或删除；如果删除某个未使用方案会导致系统没有任何有效方案，也必须拒绝删除。

## 系统内置默认方案

首次启动、方案文件缺失或旧空默认方案需要修复时，系统创建一套内置默认方案：

- 名称：`YF-S201 默认计量方案`。
- 流量计标识：`YF-S201`。
- 启动脉冲数：`8P`。
- 启动水量：`36ml`。
- 稳态 P/L：`225P/L`。
- 启动时长：`5000ms`。
- 预计稳态流速：`480ml/min`。
- 创建说明：标明这是系统内置默认参数，启动阶段约 5 秒，前 5 秒约 8 个脉冲，启动水量按 225P/L 折算。

这套方案用于保证设备烧录后立刻具备可用计量参数。它和其他方案一样可以被修改并产生 revision，也可以在存在另一套当前启用方案后按普通规则停用；但系统任何时刻都不能没有当前启用方案。

## 方案数据

每套方案保存以下结构化数据：

- `id`：稳定 ID，创建后不复用。
- `valid`：是否有效。
- `enabled`：是否可用。
- `name`：用户可编辑名称。
- `meterLabel`：流量计标识。
- `installationLabel`：水路或安装位置。
- `conditionLabel`：水压、滤芯状态或实验环境标签。
- `userNote`：用户备注。
- `startupPulseCount`：启动脉冲数。
- `startupVolumeMl`：启动水量，单位 ml。
- `stablePulsePerLiter`：稳态 P/L。
- `startupDurationMs`：启动时长，单位 ms，仅用于预计展示。
- `stableFlowMlPerMin`：预计稳态流速，单位 ml/min，仅用于预计展示。
- `sourceType`：`default`、`generated`、`manual`、`migrated`。
- `revision`：方案修订号，创建为 1，修改 5 个计量参数或环境信息时递增。
- `createdAt`：创建时间。
- `updatedAt`：最近修改时间。
- `lastActivatedAt`：最近启用时间。
- `useCount`：累计成功出水记录使用次数。
- `lastUsedAt`：最近一次用于出水记录的时间。
- `usageStatsDirty`：使用次数统计是否可能不完整。
- `sampleCount`：生成时使用的有效样本数量。
- `sampleTraceIds`：生成时参与样本的设备明细 ID 摘要。
- `minActualMl`：生成样本中的最小实测水量。
- `maxActualMl`：生成样本中的最大实测水量。
- `maxErrorMl`：生成拟合后的最大误差。
- `maxErrorPercent`：生成拟合后的最大相对误差。
- `startupDurationMinSec`：启动阶段最小时长。
- `startupDurationMaxSec`：启动阶段最大时长。
- `startupDurationMedianSec`：启动阶段中位时长。
- `startupDurationAvgSec`：启动阶段平均时长。
- `creationSummary`：创建说明。
- `lastModifiedSummary`：最近修改说明。

`sampleCount` 到 `startupDurationAvgSec` 是创建时的样本依据快照。方案后续被修改时，这些创建依据不变，只更新最近修改信息和 `revision`。`startupDurationMs` 是参与预计时间计算的计量参数，和作为样本依据快照的启动阶段统计字段不是同一类数据。

手工新建方案没有样本依据，`sourceType` 为 `manual`，样本统计字段为 0，创建说明显示“手工创建”。

## 计量方案生成结果

计量方案生成结果来自已保存样本。生成方案不会保存正式方案，也不会影响当前计量。

生成结果显示：

- 5 个计量参数，并按容量估算计量参数和时间估算计量参数分组显示。
- 样本数量。
- 实测水量范围。
- 最大误差。
- 最大相对误差。
- 启动阶段时长：中位数、平均数、最小值、最大值。
- 生成时间。

专业计量方案页的生成结果只提供两个操作：

- 保存为新方案。
- 放弃生成结果。

生成结果不能直接启用，不能覆盖已有方案，也不能覆盖当前启用方案。

保存生成结果后，系统创建一套新的流量计计量方案。保存动作不启用新方案。用户需要显式点击“启用方案”后，设备才切换计量参数。

普通校准会话中的“确认应用”是例外流程：用户已经处于校准完成上下文中，确认后系统创建并启用新方案，同时保留旧方案和生成依据摘要。

## 操作规则

### 生成结果

系统只使用已入库、容量已校准、未截断、未发生暂停后恢复出水且稳态识别成功的样本生成方案。

RAM 临时明细只用于查看和校准入口，不直接参与生成。用户在校准页样本列表中校准 RAM 明细容量时，系统必须先保存到设备样本库；入库失败时本次校准失败。

生成结果必须有明确质量门槛：

- 有效样本数量不少于 2 条。
- 样本容量覆盖小容量和大容量，最大实测水量和最小实测水量差值不少于 500ml。
- 参与样本必须保存设备明细 ID，便于追溯。
- 生成结果保存最大绝对误差和最大相对误差。
- 最大绝对误差不超过 100ml，最大相对误差不超过 5%。超过阈值时，只显示诊断结果，不生成可保存结果。
- 若同一容量附近有多次样本，应记录重复性差异。相邻实测水量差值不超过 200ml 的样本视为同一容量附近。
- 稳态识别失败、暂停恢复、明细截断或未确认实际容量的样本不能参与生成。

质量门槛不满足时，页面只能显示诊断原因，不能生成可保存的生成结果。

### 保存为新方案

保存生成结果时只能创建新方案，不允许选择已有方案覆盖。

如果底层工程容量已满，保存失败并提示先删除未使用过的方案。

保存成功后，生成结果可以清空，避免重复保存同一结果。

### 新建计量方案

用户可以手工新建方案，填写：

- 方案名称。
- 启动脉冲数。
- 启动水量。
- 稳态 P/L。
- 启动时长。
- 预计稳态流速。

手工新建方案不需要样本依据，不自动启用。

### 修改计量方案

修改页允许编辑：

- 方案名称。
- 流量计标识、水路或安装位置、环境标签和备注。
- 启动脉冲数。
- 启动水量。
- 稳态 P/L。
- 启动时长。
- 预计稳态流速。

修改不改变创建依据。系统只更新 `updatedAt` 和 `lastModifiedSummary`。

如果修改的是当前启用方案，保存后会立即影响后续容量估算和预计展示，页面必须明确提示这一点。

修订号规则：

- 新建方案的 `revision` 为 1。
- 修改 5 个计量参数时，`revision` 必须递增。
- 修改流量计标识、水路或安装位置、环境标签、备注时，`revision` 必须递增，因为这些字段会改变方案适用条件。
- 只修改方案名称时，`revision` 不递增。
- 后续历史记录展示以出水记录中的计量快照为准，不能用方案当前 revision 的参数反推历史。

已经被出水记录使用过的方案仍允许修改，但每次影响计量或适用条件的修改都必须形成新的 `revision`。创建依据始终代表最初创建时的样本快照，最近修改信息代表当前方案最近一次修改。

### 启用方案

启用是单独操作。只有启用后，方案才成为当前计量方案。

只有可用方案可以启用。停用方案需要先恢复为可用，再启用。

启用方案时更新：

- `activeSchemeId`
- 方案的 `lastActivatedAt`
- 运行时 `FlowMeter` 使用的计量参数

启用不修改方案的创建依据或最近修改说明。

### 停用与删除方案

当前计量方案不能停用，也不能删除。若用户要停用或删除当前方案，必须先启用另一套可用方案。

已经被出水记录使用过的方案不能删除，只能停用。停用后不出现在日常启用选择中，但仍保留在停用方案列表和历史追溯中。

从未被使用过、非当前且不是最后一套有效方案的方案可以真正删除。删除后释放存储空间，方案 ID 仍不复用。

系统必须始终保留至少一套可用方案，并且 `activeSchemeId` 必须指向一套可用方案。

## 出水记录追溯

每条成功生成的出水记录必须保存当时的计量快照：

- `meteringSchemeId`
- `meteringSchemeRevision`
- `startupPulseCount`
- `startupVolumeMl`
- `stablePulsePerLiter`
- `startupDurationMs`
- `stableFlowMlPerMin`

这些字段用于保证历史记录不依赖方案是否仍处于可用状态。方案中的 `useCount` 是累计使用次数，用于页面显示“使用 N 次”并判断是否允许物理删除。

使用次数一致性规则：

- 只有出水记录成功写入后，才增加对应方案的 `useCount`。
- 如果出水记录写入失败，不增加 `useCount`，避免方案状态和历史记录不一致。
- `useCount` 是累计值，不因历史记录环形覆盖而减少。
- `lastUsedAt` 在成功写入出水记录后同步更新。
- 如果更新 `useCount` 或 `lastUsedAt` 失败，设备应记录告警，并把该方案的 `usageStatsDirty` 标记为 true。
- 不通过扫描出水记录重建 `useCount`。出水记录是环形覆盖，扫描结果不能代表累计使用次数。
- `usageStatsDirty` 为 true 时，页面显示“使用次数可能不完整”。
- 删除判断必须保守：只要 `useCount > 0` 或 `usageStatsDirty = true`，都不允许物理删除，只允许停用。

## 页面结构

计量方案页按任务分区：

1. 当前计量方案
   - 显示当前启用方案名称。
   - 显示 5 个计量参数，并区分容量估算计量参数和时间估算计量参数。
   - 明确提示时间估算计量参数只用于预计展示，不参与实际容量、滤芯累计或统计累计。
   - 显示创建来源、样本依据和最近修改。

2. 计量方案生成结果
   - 显示生成结果和样本依据。
   - 提供“保存为新方案”和“放弃生成结果”。
   - 明确提示“保存不会自动启用”。

3. 流量计计量方案
   - 动态列表显示已有方案。
   - 当前启用方案有明确标记。
   - 每套方案显示名称、参数摘要、来源、样本摘要、使用次数和最近修改。
   - 可用方案操作包括“启用”“修改”“停用”或“删除”。
   - 停用方案默认折叠，操作包括“恢复为可用”“修改”和“查看”。
   - 从未使用过、非当前且不是最后一套有效方案的方案才显示“删除”。

4. 新建计量方案
   - 提供手工新建入口。
   - 表单分组显示容量估算计量参数和时间估算计量参数。
   - 新建后不自动启用。

5. 样本库摘要
   - 展示长期样本库的覆盖范围和有效样本数量。
   - 显示容量校准、稳态识别、是否可参与生成。
   - 本次校准会话的出水、实测容量录入和放弃本次样本不在本页操作，统一放在 `/faucet/calibration`。

校准页只承担普通校准会话：进入/退出校准模式、录入本次实测容量、放弃本次样本、生成并确认应用。它不提供手工方案管理、长期样本库生成、方案启用列表或测算工具。

## 存储策略

流量计计量方案应从 `SystemConfig` 中拆出，使用独立的 `MeteringSchemeStore` 管理。

`SystemConfig` 继续保存安全阈值、显示、蜂鸣器、滤芯、预设等系统配置。流量计计量方案独立保存：

- 计量方案存储版本。
- 当前启用方案 ID。
- 下一个方案 ID。
- 方案数量。
- 方案记录。
- 计量方案生成结果。

保存方案时只写入被修改的方案和必要索引，不重写整个系统配置。启用只写当前启用 ID 和被启用方案的启用时间；停用、恢复、修改和删除只写对应方案记录。这样可以减少写入量，降低 Flash 磨损。

方案数量不再是固定小数组，因此方案记录适合使用独立记录式持久化。当前启用 ID、存储版本和少量索引可以放在 NVS；方案记录可以放在 LittleFS 定长记录文件或等价的记录式存储中。脉冲明细样本使用独立样本库，不放入方案配置。

普通校准会话样本和长期样本库使用独立空间：

- RAM：只保留当前/最近一次完整脉冲明细。
- 会话样本区：Flash 固定 5 槽位，新会话开始时清空并覆盖。
- 长期样本库：Flash 固定 10 槽位，不自动覆盖。

计量方案页从长期样本库生成方案；校准页从当前会话有效样本生成并确认应用。

## 迁移规则

从旧固定编号计量配置迁移时：

- 旧配置中的当前启用计量参数迁移为一套方案，作为当前计量方案。
- 其他槽如果有效且不是默认参数，迁移为独立方案。
- 默认但未实际使用的空意义槽不迁移。
- 旧生成结果如果存在，迁移为计量方案生成结果。
- 旧创建说明和最近修改说明尽量保留到新方案对应字段。
- 旧配置没有时间估算计量参数时，`startupDurationMs` 填入 `5000`，`stableFlowMlPerMin` 填入 `480`，并在说明中标明这些时间估算参数来自迁移默认值。
- 迁移出的方案默认标记为可用，使用次数从 0 开始。
- 迁移完成后不再读写旧固定编号计量字段。
- 如果设备只存在旧版空默认方案，升级时修复为系统内置 `YF-S201 默认计量方案`，避免继续使用旧的空启动参数。

迁移必须保护用户已有配置，不能因升级静默清空可识别方案。

## 文案原则

- 不使用固定位置编号作为用户概念。
- 不使用“覆盖当前方案”作为生成结果保存动作。
- “保存为新方案”和“启用方案”必须分开。
- 所有会影响当前计量的操作必须显式提示。

# 脉冲分段计量参数说明

本文是“脉冲分段计量参数”和“流量计计量方案”的用户说明，用来统一页面概念、参数含义和校准流程。它只描述用户需要理解和操作的内容，不描述代码实施步骤。

## 设计边界

旧的“控制 P/L、启动补偿、启动等效”等概念不再作为页面概念、文档概念或代码设计概念保留。

新的计量模型只保留 3 个真正参与运行时计量的核心字段：

- 启动脉冲数
- 启动水量
- 稳态 P/L

这些字段保存在“流量计计量方案”中。方案和具体流量计、水路、水压、滤芯状态、安装环境有关，可以保存多套用于实验、对比、回滚和不同场景切换。

## 要解决的问题

当前设备用单一 P/L 系数估算出水量。大容量出水时，这个系数通常比较稳定；但小容量出水时，开阀初期的水流爬坡会占比较大，容易出现偏差。

新的计量模型把一次出水分成两段：

- 启动段：开阀后的前几个脉冲，水流还没有完全稳定。
- 稳态段：水流稳定后的脉冲，按稳定 P/L 计算。

这样做的目标是让小容量和大容量都能用同一套参数解释，而不是用一个全程平均 P/L 去硬套所有容量。

## 核心概念

### 流量计计量方案

流量计计量方案是一套可保存、可启用的水量换算参数。系统最多保存 10 套方案，页面按动态列表展示已有方案。

每套方案真正参与计量的字段只有 3 个：

- 启动脉冲数：启动段包含多少个脉冲。
- 启动水量：启动段这些脉冲对应多少 ml 水。
- 稳态 P/L：进入稳定流量后，每升水对应多少个脉冲。

除这 3 个字段以外，生成方案时用到的样本数量、容量范围、最大误差、启动阶段时长等信息，都作为创建依据保存，后续修改方案时不改变这些创建依据。

### 当前计量方案

当前计量方案是设备正在用于出水估算的方案。只有显式执行“启用方案”后，设备才切换当前计量方案。

### 候选计量方案

候选计量方案是根据当前已保存样本生成出来的结果。候选不会自动保存为正式方案，也不会自动启用。

候选确认后只能保存为新方案。保存新方案后仍不会自动启用，需要用户再显式启用。

### 启动阶段时长

启动阶段时长只表示生成方案时，样本中观察到“进入稳态大概需要多久”。它不是控制边界，不参与计量公式，也不作为独立计量参数使用。

页面可以显示为：

```text
启动阶段时长：中位 5s，平均 5.4s，范围 3-8s
```

如果平均值明显偏离中位数，或范围很散，例如 2-15s，说明启动过程波动大，这套方案需要谨慎启用。

### 全程平均 P/L

全程平均 P/L 不能作为独立系统参数，因为它会随出水量变化。

它只能出现在有明确水量上下文的位置：

- 历史记录：本次总脉冲和本次实测水量对应的全程平均。
- 容量预设：当前计量方案下，某个目标容量预计会表现出来的等效全程平均。

页面不应单独显示一个没有上下文的“全程平均 P/L”。

## 计量逻辑

设：

```text
P  = 当前累计有效脉冲数
Ns = 启动脉冲数
Vs = 启动水量，单位 ml
Ps = 稳态 P/L
V  = 估算出水量，单位 ml
```

计量公式为：

```text
P = 0:
  V = 0

0 < P <= Ns:
  V = round(P * Vs / Ns)

P > Ns:
  V = Vs + round((P - Ns) * 1000 / Ps)
```

含义是：前 `Ns` 个脉冲按启动段估算，超过 `Ns` 后按稳态 P/L 估算。

`Ns = 0` 且 `Vs = 0` 时，启动段等价于没有，全部有效脉冲按稳态 P/L 计算。

## 参数从哪里来

参数可以来自两种方式：

1. 根据样本生成候选计量方案。
2. 手工新建计量方案。

一个样本要参与生成候选，需要同时满足：

- 有脉冲明细。
- 已输入或确认量杯实测水量。
- 能识别出稳定流量段。
- 已保存到设备样本库。

RAM 临时明细只用于查看和判断，不能直接参与生成。需要参与生成时，用户先把它保存到设备。

## 方案数据

每套流量计计量方案保存：

- 方案名称。
- 启动脉冲数。
- 启动水量。
- 稳态 P/L。
- 创建来源：样本生成、手工创建、迁移或默认。
- 创建时间。
- 最近修改时间。
- 最近启用时间。
- 样本数量。
- 样本实测水量范围。
- 最大误差。
- 启动阶段最小时长。
- 启动阶段最大时长。
- 启动阶段中位时长。
- 启动阶段平均时长。
- 创建说明。
- 最近修改说明。

样本数量、容量范围、最大误差和启动阶段时长是创建时的样本依据快照。后续修改方案时，这些创建依据不变，只更新最近修改信息。

手工新建方案没有样本依据，创建来源记录为“手工创建”。

## 操作流程

推荐流程：

1. 按常规方式本地出水。
2. 在校准页确认最新记录的实际容量。
3. 查看脉冲明细，确认样本质量。
4. 把合格明细保存到设备样本库。
5. 积累多个容量的有效样本。
6. 手动生成候选计量方案。
7. 检查候选方案的核心参数、样本数量、容量范围、误差和启动阶段时长。
8. 如果结果合理，保存为新方案。
9. 需要实际使用时，再显式启用该方案。
10. 再用不同容量复测。

## 操作规则

- 生成候选计量方案：只产生候选，不保存正式方案，不影响当前出水。
- 保存为新方案：只能创建新方案，不能覆盖已有方案，不能覆盖当前方案，不自动启用。
- 新建计量方案：手工填写名称和 3 个核心参数，不自动启用。
- 修改计量方案：可修改名称和 3 个核心参数；如果修改当前方案，保存后立即影响计量，页面必须明确提示。
- 启用方案：显式切换当前计量方案。
- 删除方案：只允许删除非当前方案，系统必须始终保留至少一套有效方案。

## 推荐页面结构

校准页建议按用户任务分成 5 块：

1. 当前计量方案
   - 显示当前启用方案名称。
   - 显示启动脉冲数、启动水量、稳态 P/L。
   - 显示创建来源、样本依据和最近修改。

2. 候选计量方案
   - 显示根据当前样本生成的新方案。
   - 明确提示“生成后不会自动保存或启用”。
   - 提供“保存为新方案”和“丢弃候选”。

3. 流量计计量方案
   - 显示已有方案动态列表。
   - 每套方案可以查看、启用、修改或删除。
   - 当前方案有明确标记。

4. 新建计量方案
   - 支持手工输入名称、启动脉冲数、启动水量和稳态 P/L。
   - 新建后不自动启用。

5. 样本区
   - 显示 RAM 临时样本和已保存样本。
   - 显示容量是否已确认、稳态是否识别成功、是否可参与生成。
   - 支持保存或删除样本。

## 页面文案原则

- 不再使用旧概念，例如“控制 P/L”“启动补偿”“启动等效”。
- 页面优先使用“当前计量方案”“候选计量方案”“流量计计量方案”“启动脉冲数”“启动水量”“稳态 P/L”。
- 所有会改变当前计量行为的动作，都要明确显示结果，例如“启用此方案”。
- 生成候选计量方案要明确提示“不保存、不启用”。
- 保存候选必须写成“保存为新方案”。
- 保存为新方案要明确提示“不自动启用”。
- 全程平均 P/L 只跟具体记录或具体预设一起显示。

## 后续实现约束

后续代码实现应以新模型为唯一运行时计量模型：

- 出水计量不再使用“单一 P/L + 启动补偿”。
- 配置中不再保存“控制 P/L、启动补偿、启动等效”这些独立概念。
- 流量计计量方案应独立于系统业务配置持久化，保存当前方案、候选方案和最多 10 套正式方案。
- 历史配置升级时，只允许把旧可识别字段迁移成新的流量计计量方案，迁移后不再继续保存旧字段。
- 方案中只有 3 个核心参数是结构化计量字段；样本统计、启动阶段时长范围、中位数、平均数和误差等作为创建依据保存。
- 页面、API 和测试用例都应使用新概念命名。

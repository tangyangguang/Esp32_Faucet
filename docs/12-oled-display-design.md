# 0.91 寸 OLED 本地屏设计定稿

## 定稿结论

本项目后续本地显示默认使用 0.91 寸 I2C OLED 屏，保留 LCD1602 支持但默认不启用。OLED 界面不照搬 LCD1602 的两行文本模型，而是按 128x32 小屏重新设计信息层级：只展示用户当下需要知道、且不影响本地出水安全闭环的信息。

高保真原型定稿：

- HTML：`docs/prototypes/oled-091-high-fidelity.html`
- 完整设计板：`docs/prototypes/oled-091-high-fidelity-full.jpg`
- 主视觉截图：`docs/prototypes/oled-091-high-fidelity-hero.jpg`

## 硬件和配置

- 显示设备通过系统配置选择，新增显示设备类型字段。
- 可选值：
  - `OLED 0.91`：0.91 寸 I2C OLED，本项目默认值。
  - `LCD1602`：旧 I2C LCD1602，代码保留，可配置启用。
- OLED 连接方式为 I2C，复用当前 SDA/SCL 总线。
- OLED 首版实现按常见 128x32 SSD1306 类 I2C OLED 设计；默认地址建议先按 `0x3C` 实现，实际上板时通过 I2C 扫描确认。
- LCD1602 地址配置继续保留，仅在选择 LCD1602 时生效。
- OLED 相关地址或驱动型号如果需要配置，应作为重启生效项，不在出水运行中切换。

建议配置模型：

```cpp
enum class DisplayDevice : std::uint8_t {
    Oled091 = 0,
    Lcd1602 = 1,
};
```

建议配置键：

- `display_device`：显示设备类型，默认 `oled091`。
- `oled_addr`：OLED I2C 地址，默认 `0x3C`。
- `lcd_addr`：LCD1602 I2C 地址，保留当前配置。

## 产品边界

OLED 的职责是服务本地高频操作和安全判断，不承担 Web 管理页职责。

必须展示：

- 待机目标水量或目标时间。
- 今日累计、水温、TDS 水质摘要。
- 确认页目标值、步进、预计时间或预计水量。
- 运行中已出水、剩余量或剩余时间、实时流速、进度。
- 暂停状态、已出水、剩余量或剩余时间。
- 结果页总出水量、耗时、平均流速、校准入口提示。
- 安全异常原因，例如无水流、高流量、超量、安全停止。

只做低优先级提示：

- 离线、配网。
- 存储异常、RTC 缺失、传感器故障。
- 滤芯建议更换或已超期。
- 水温/TDS 未校准或可信度不足。

不在 OLED 展示：

- 输入电压。输入电压只作为 Web/日志诊断信息。
- 详细 WiFi 状态、IP、RSSI、OTA 入口。
- 出水历史记录列表。
- 滤芯完整列表和编辑入口。
- 复杂校准参数、历史计量方案、脉冲明细。
- 任何远程控水入口或 Web 控水状态。

## 页面集合

定稿页面共 15 类，分为主流程和低优先级提示。

主流程页面：

1. 待机：容量预设，信息一次展示。
2. 待机：时间预设。
3. 确认：目标确认。
4. 运行：容量模式，展示流速和进度。
5. 运行：时间模式，展示剩余秒数和流速。
6. 暂停：状态主导，操作提示降级。
7. 结果：完成摘要。
8. 异常：安全异常原因最大化。
9. 校准：采样读数。
10. 校准录入：实测量调整。

低优先级提示页面：

11. 系统提示：离线待机。
12. 系统提示：配网模式。
13. 系统异常：存储告警。
14. 维护提示：滤芯建议更换。
15. 传感器提示：水质未校准。

## 信息层级规则

- 主字号只给业务值：目标值、已出水、剩余量、结果值、异常原因。
- 预设编号不进入主视觉；最多作为小标签显示，默认可以不显示。
- 操作提示只做小字，不放大 `OK`、`CANCEL`、`PLUS`、`MINUS`。
- 待机页不轮播传感器页，默认一次展示目标、今日累计、水温、TDS。
- 出水运行中不显示网络、滤芯、传感器校准等低优先级提示。
- 安全异常优先级高于所有系统提示，必须先关阀，再显示异常原因。
- 系统提示只在待机、结果或空闲提示页面出现，不得覆盖运行页核心读数。

## 运行页数据展示

运行页图表必须表达真实状态，不做装饰性假动画。

数据来源：

- `已出水`：当前出水量。
- `目标值`：本次 active target。
- `剩余`：目标值减已出水，或目标时长减已运行时长。
- `流速`：面向用户展示的平滑实时流速。
- `进度条`：`已出水 / 目标值`，定时模式用 `已运行时长 / 目标时长`。
- `流速曲线`：最近若干个显示流速采样值，建议 6-8 个点。

实现约束：

- 运行页刷新必须节流，避免阻塞控制 tick。
- 曲线只用于趋势提示，不参与控制、安全判断、统计或记录。
- 流速显示口径应使用当前项目的 `displayFlowMlPerMin` 或等价用户展示字段，不混用瞬时诊断流速。

## 状态优先级

从高到低：

1. 安全关阀异常：无水流、高流量、超量、安全停止、暂停超时。
2. 运行中主信息：已出水、剩余、流速、进度。
3. 本地交互状态：确认、暂停、结果、校准录入。
4. 待机摘要：目标、今日累计、水温、TDS。
5. 系统提示：离线、配网、存储异常、RTC、传感器、滤芯。
6. 纯诊断信息：输入电压、详细日志、脉冲明细，只在 Web 展示。

## 实现建议

建议不要让 OLED 驱动直接消费旧 `DisplayFrame`。旧 `DisplayFrame` 是 LCD1602 的 16x2 字符帧，无法表达 OLED 的数值、进度和状态层级。

建议分层：

- `DisplayPresenter` 或新 presenter 负责从 `AppSnapshot` 生成平台无关的本地显示快照。
- `Lcd1602Display` 继续消费 LCD1602 文本帧。
- `Oled091Display` 消费 OLED 专用绘制快照。
- `DisplayDevice` 配置决定主循环调用哪个硬件输出。

建议新增或拆分模型：

- `OledSnapshot`：OLED 页面、主数值、副数值、系统角标、维护角标、流速采样。
- `SystemBadge`：离线、配网、存储异常、RTC 缺失、传感器异常。
- `MaintenanceBadge`：滤芯建议更换、滤芯已超期、水质未校准。
- `FlowTrendBuffer`：保存最近 6-8 个显示流速采样点。

## 字体和体积风险

OLED 中文界面需要中文字库。当前 Flash 使用率已进入预警区间，不能直接引入完整中文字库。

建议：

- 只打包本设计中用到的固定中文词点阵。
- 数字和单位优先使用轻量字体或内置 ASCII 字体。
- 固件实现前先列出完整字表，评估 Flash 增量。
- 如体积超标，优先压缩低优先级提示页字库，而不是牺牲运行页读数。

## 验证要求

- 修改显示设备配置、配置存储或 Web 配置项后，运行 `pio test -e native`。
- 修改主固件集成、驱动接入、构建参数或库依赖后，运行 `pio run -e esp32dev`。
- OLED 运行页必须验证不会阻塞控制 tick。
- Web 仍不得新增任何远程控水接口。
- 出水中网络、滤芯、传感器提示不得覆盖运行主信息。
- 安全异常必须优先关阀，再显示异常页。

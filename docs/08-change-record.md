# 变更记录

## 2026-05-29 校准工作台与脉冲分段计量参数

- 顶层导航新增 `/faucet/calibration` 校准页；记录页回归历史记录和脉冲明细入口，不再承载计量诊断和容量校准入口。
- `/faucet/calibration` 同时注册 GET 页面和 POST 操作路由，校准页表单提交后回到校准页，不再落到不存在的 API 页面。
- “容量校准”改为“确认/校准容量”：估算准确时直接确认，不准确时输入量杯读数；保存只记录最后一条出水记录的确认容量，并同步匹配的 RAM/文件明细实测值，不触发分段拟合、参数生成或系统参数应用。
- 对应脉冲明细的设备存储改为独立操作：未保存时显示“保存到设备”，已保存时显示“删除已保存明细”，不再和容量校准表单绑定。
- 校准页新增紧凑的“最后一条出水记录”和“样本”区；确认容量改为最新记录行内表单，不再跳到同页下方卡片；样本区同时展示 RAM 临时明细和已保存设备明细，并通过“待确认容量”“容量已确认”“稳态失败”“可入库”“可参与生成”等标签说明状态。
- 校准页样本和最新记录进入明细时使用 `/faucet/calibration/detail` 隐藏路径，顶部导航保持“校准”；记录页入口仍使用 `/faucet/records/detail` 并保持“记录”。
- 校准页顶部诊断保留“计量状态”“RAM 最近明细”“已保存明细”；样本覆盖信息移动到“计量方案生成”区，避免把生成条件和运行状态混在一起。RAM 最近明细按系统配置的 `recentPulseTraceCount` 显示上限，底层 RAM 明细容量固定为 `kMaxRecentPulseTraceCount`。
- 最新记录和样本列表的明细来源标签可直接进入脉冲明细页；校准工作台外层不再提供保存或删除明细按钮，保存/删除统一在明细页完成。
- 最新记录的确认容量改为表格行下展开表单，估算出水和确认容量分列展示，避免把估算值、实测值和操作输入挤在同一格。
- 样本列表新增“前 N 秒脉冲”观察列，样本区可设置 1-60 秒窗口，默认 10 秒，用于查看启动阶段脉冲分布。
- 运行时计量改为 3 个核心字段：启动脉冲数、启动水量、稳态 P/L；统一抽象为“流量计计量方案”，用于保存和切换多套实验参数。
- 计量方案生成结果由样本生成，生成后不保存、不启用；确认后只能保存为新方案，不能覆盖已有方案或当前启用方案。
- 流量计计量方案按动态列表展示；启用方案是独立操作，已使用方案只能停用，未使用的非当前方案可以删除。
- 方案创建时保存样本数量、容量范围、最大误差、启动阶段最小/最大/中位/平均时长等创建依据；后续修改方案只更新最近修改信息，不改创建依据。
- 校准页样本列表、历史记录和首页今日接水记录均按时间倒序显示，最新记录在最上方。

## 2026-05-27 本地步进、LCD 与计量记录

- 修复手动暂停后取消停止导致上一轮出水量污染下一轮确认页调整下限的问题。
- 本地确认页容量和时间目标改为按 Web 配置步进调整，默认容量 0.10L、时间 10s；长按 `OK` 不再切换 0.10L/0.50L，暂停页不再允许调整目标。
- LCD1602 页面重排，所有醒屏页面第一行右侧固定显示每升脉冲数；本地 LCD 只显示预设编号与容量/时间，不显示预设名称。
- 系统配置新增本地容量/时间调整步进；迁移保留旧预设、滤芯、统计、记录和可识别计量值。
- Web 记录页精简为高频字段，取消固定“诊断”列；脉冲列显示原始脉冲和 P/L，过滤脉冲只在有值时作为辅助信息。新增独立记录校准元数据文件，保存实测量和重校次数；校准后记录页显示“已校准”和实测量，重校默认上次实测量。

## 2026-05-16 原型评审收口

- P2-15：正式文档补充出水记录时间回溯不依赖 32 位 `uptimeMs`；未同步时间只保存启动内相对秒和 boot id，NTP 同步后通过 Esp32Base boot event 回写真实时间。
- P2-18：26/27/28 原型评审结论并入正式文档，不再把独立评审稿作为实现依据；records 首版必须支持时间范围筛选，并在 `docs/03-software-architecture.md` 与 `docs/06-implementation-plan.md` 中作为正式范围维护。

## 2026-05-15 Records 重整与校准入口收敛

- 统一产品概念为出水记录 `records`，业务页面从 `/faucet/logs` 改为 `/faucet/records`。
- 业务 API 从 `/api/faucet/logs` 改为 `/api/faucet/records`，JSON 顶层数组字段从 `logs` 改为 `records`。
- 删除独立校准页 `/faucet/calibration` 和旧校准 API `/api/faucet/calibration`。
- 新增记录校准保存能力，当前统一通过 `POST /api/faucet/records` 携带 `action=calibrate` 和 `actualMl` 提交。
- 删除 4 个校准候选容量配置，配置保存后不再写入 `cal_ml`、`cal0_ml`、`cal1_ml`、`cal2_ml`、`cal3_ml`。
- 删除旧校准采样控制器，校准公式统一为 `newPulsePerMl = pulseCount / actualMl`。
- 出水记录 LittleFS 文件改为 `/faucet_records_v1.bin`，文件 header 使用 records 语义 magic/version。
- 流量计计量参数从系统参数页移出，统一由业务校准页的“流量计计量方案”管理；每套方案保存启动脉冲数、启动水量和稳态 P/L。
- 系统配置版本从 v4 升到 v5；v5 加载保留安全、阀门、显示、预设、滤芯、流量系数等有效字段，忽略旧校准候选容量字段。

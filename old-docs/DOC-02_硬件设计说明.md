## 1. 系统框图
```
[220V市电输入] ──[船型硬开关]──[12V/2A适配器]──┬──[电磁阀（12V独立供电）]
                                                └──[MP1584 12V→5V]──┬──[AMS1117 5V→3.3V]──[ESP32主控]──┬──[IIC总线：OLED/DS3231]
                                                                                                       ├──[流量传感器]
                                                                                                       ├──[EC11编码器 + 红/绿独立按键]
                                                                                                       ├──[蜂鸣器]
```
✅ 大负载电磁阀独立供电，与主控电路单点共地，避免干扰；外部硬开关切断总电源，彻底断电。

## 4. 电源设计
| 参数 | 数值 | 说明 |
|------|------|------|
| 输入电压 | 12V DC | 来自220V转12V 2A适配器，外部串船型总开关 |
| MCU 工作电压 | 3.3V | AMS1117-3.3 LDO稳压 |
| 外设供电 | 5V DC | MP1584 DC-DC稳压 |
| 执行器（电磁阀）供电 | 12V DC / 0.5A | 独立走线，与主控单点共地 |
| 最大总电流 | ≤1.2A | 含电磁阀吸合峰值电流0.3A+余量 |

**设计要求**：
- MCU每个电源引脚放置100nF去耦电容，距离引脚≤2mm
- 12V和5V电源入口各放置10µF滤波电容
- 电磁阀供电线宽≥1mm，压降≤0.1V
- 模拟地和数字地单点共地，避免干扰流量计数

## 6. 关键电路说明
### 6.1 电磁阀驱动电路
采用IRLR7843 N沟道MOSFET作为开关元件，栅极串1K限流电阻，漏极接电磁阀正极，电磁阀负极接12V电源正极，续流二极管SS34反向并联在电磁阀两端。3.3V IO可直接驱动，导通电阻<1mΩ，几乎无发热，支持最大160A电流，远大于电磁阀0.3A需求，余量充足。低功耗PWM驱动时稳定性极高。

### 6.2 流量计数电路
YF-S201输出为开漏脉冲，串10K上拉电阻到3.3V，输入端并联100nF滤波电容滤除水流波动和电磁干扰，直接接入ESP32外部中断引脚，双边沿触发计数，精度更高。

### 6.3 电源电路
采用两级稳压方案：12V输入经外部船型开关后给电磁阀供电，同时经MP1584 DC-DC转换为5V给外设供电，再经AMS1117-3.3 LDO转换为3.3V给ESP32供电，纹波<10mV，抗干扰能力强，WiFi工作稳定。外部硬开关可切断全部电源，物理关阀。

## 设计优化说明
1. **按键操作逻辑优化**：高频操作全部分配给独立绿键，EC11中键仅用于低频菜单操作，完全避免旋转误触发问题，操作手感提升明显
2. **双重关阀安全**：软件红键快速关阀+外部硬开关物理断电，双重保护无漏洞
3. **元件选型适配**：全部使用您已有库存的IRLR7843和SS34，性能比原设计更强，发热更低

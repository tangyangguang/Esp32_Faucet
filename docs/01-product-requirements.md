# 产品需求草案

## 当前已确认原则

- 本项目是家庭净水器智能定量出水龙头，目标是减少接水值守和溢水风险。
- 旧版 `old-docs/` 作为需求背景参考，但不直接继承旧架构和历史兼容性。
- 基础能力全部通过 Esp32Base 提供；基础库能力缺口通过 `docs/base-library-requests/` 记录提示词后回到基础库完善。
- 新方案取消 EC11，使用 `STOP`、`OK`、`NEXT` 三个功能按键。
- 目标是方便使用、安全可靠、不过度设计；优先做好日常接水和异常关阀。

## 实现范围草案

### 需要实现

- 定量出水：支持常用预设，一键选择、二次确认、自动关阀。
- 定时出水：作为次要模式保留，主要通过 Web 配置预设，本地只负责选择和启动。
- 预设管理：保留 9 组预设能力，默认启用 1.5L 和 7.5L，其余默认禁用；9 组预设占用资源很小，减少数量对 Flash/RAM 收益不明显，保留更利于不同容器使用。
- 三键本地操作：`STOP` 负责停止/取消/返回，`OK` 负责确认/启动/暂停继续，`NEXT` 负责切换。
- 软件停止：任意状态下 `STOP` 按下后立即软件关阀，优先级最高；硬件停止由外部电源开关完成，不进入软件设计范围。
- 安全兜底：最大出水时间、最大出水量、超过预设百分比、开阀后无流量、异常大流量均自动关阀。
- 流量校准：支持本地校准向导，使用已知容量容器、多次采样、一致性检查和确认保存；Web 不允许启动校准出水，只允许查看或手动修改校准参数。
- OLED 显示：显示当前预设、运行状态、剩余量/时间、错误、IP 查询等必要信息。
- Web 管理：提供配置、预设、校准参数查看/手动修改、日志、统计、滤芯基础查看、WiFi/OTA 入口；Web 端不提供任何启动出水、暂停出水、继续出水或停止出水操作。
- 日志记录：尽量多保存出水记录用于分析，支持 Web 分页查询；按 20000 条作为容量目标，最终以 LittleFS 空间和性能验证后的合理值为准。
- 统计：支持今日、本周、本月、总累计出水量。
- 断网运行：WiFi 断开不影响本地出水、停止和显示。
- 滤芯管理：支持最多 6 个滤芯，Web 可配置每级滤芯启用状态、名称、寿命天数、寿命流量和上次更换日期；页面显示已使用天数、已使用流量和寿命设置，支持重置更换时间与累计流量；不做复杂寿命算法。
- 蜂鸣器提示：操作短提示、完成提示、异常报警，可 Web 开关。
- OTA：使用 Esp32Base Web OTA。
- 低功耗：实现 OLED 熄屏，不要求 modem sleep。
- DS3231 RTC：支持自动检测；没有 RTC 时依赖 NTP，断网日志可使用相对时间。

### 不做

- 不做语音控制。
- 不做原生 App。
- 不接入云平台。
- 不做多设备联动。
- 不接入 Home Assistant。
- 不实现 TDS 水质检测。
- 不实现漏水检测。
- 不实现三段非线性流量补偿。
- 不在本项目实现 Esp32Base 已提供或应提供的基础能力。

## 设计取舍

- 本地按键只服务高频和兜底操作，完整配置放 Web。
- 不追求实现所有旧文档高级项，先保证“按得明白、关得及时、坏了安全”。
- 日志、统计和滤芯功能保持轻量，不影响控水实时性；滤芯只做配置、累计和人工重置，不做自动拦截出水。
- 默认策略偏安全：断电或重启后不自动继续出水。
- 本地菜单不允许修改预设值；预设、滤芯、WiFi、OTA 等复杂操作均在 Web 端完成；流量校准例外，必须支持在本地完成，因为校准过程需要人在设备旁观察实际水量。
- 恢复出厂需要 OLED 二次确认，避免组合键误触造成配置丢失。

## 已确认配置

- Web 默认账号密码为 `admin/admin`。
- Web 配置页显示修改默认密码提示，但不强制修改。
- DS3231 按自动检测实现，有则使用，无则降级。

## 默认参数

| 参数 | 默认值 | 范围/说明 |
| --- | --- | --- |
| 预设数量 | 9 组 | 固定数量 |
| 预设 1 | 定量 1500ml，启用 | 名称：1.5L |
| 预设 2 | 定量 7500ml，启用 | 名称：7.5L |
| 预设 3-9 | 禁用 | 可在 Web 配置为定量或定时 |
| 定量预设范围 | 100-20000ml | Web 配置 |
| 定时预设范围 | 5-1800s | Web 配置 |
| 二次确认超时 | 10s | 本地启动出水前确认 |
| 最大出水时间 | 1800s | 安全兜底 |
| 最大出水量 | 30000ml | 安全兜底 |
| 超预设百分比 | 10% | 定量任务兜底 |
| 开阀无流量超时 | 3s | 异常关阀 |
| 异常大流量阈值 | 30L/min 持续 5s | 异常关阀 |
| 暂停超时 | 300s | 超时停止并记录 |
| 流量系数 | 0.45 pulse/ml | 可本地校准或 Web 手动修改 |
| 校准采样目标 | 1000ml | 本地可选 500/1000/1500/2000ml |
| 校准采样次数 | 至少 2 次 | 偏差不超过 5% 才允许保存 |
| 电磁阀全压吸合 | 3s | 之后进入 PWM 保持 |
| 电磁阀保持占空比 | 30% | Web 配置，范围 20-100% |
| OLED 熄屏时间 | 30s | 无操作后熄屏 |
| 蜂鸣器 | 开启 | Web 可关闭 |
| 滤芯数量 | 最多 6 个 | 可配置名称、启用、寿命天数、寿命流量、上次更换日期 |
| 滤芯默认寿命天数 | 180 天 | Web 可配置，0 表示不按天数管理 |
| 滤芯默认寿命流量 | 0ml | 0 表示不按流量管理 |
| 日志分页大小 | 默认 50，最大 200 | Web 查询 |
| Web 账号密码 | admin/admin | 配置页提示修改，不强制 |

# 脉冲分段计量

本页是分段计量的工程说明，最终规则以 `docs/脉冲分段计量参数说明.md` 为准。

## 运行时参数

运行时只使用 3 个核心字段：

- 启动脉冲数 `Ns`
- 启动水量 `Vs`
- 稳态 P/L `Ps`

系统固定支持 4 个参数槽。用户可以修改槽名称；手动创建或编辑参数槽时，只能编辑名称和 3 个核心字段。

## 计量公式

设本次有效脉冲数为 `P`：

- `P = 0`：估算水量为 `0`
- `0 < P <= Ns`：估算水量为 `round(P * Vs / Ns)`
- `P > Ns`：估算水量为 `Vs + round((P - Ns) * 1000 / Ps)`

`Ns = 0` 或 `Vs = 0` 时，启动段等价于 0，全部有效脉冲按稳态 P/L 计算。

## 候选参数

校准页从已保存到设备、容量已确认且稳态识别成功的样本生成候选参数。候选参数不会直接启用，必须保存到参数槽：

- 保存到非当前启用槽位：只覆盖该槽位，不自动启用。
- 保存到当前启用槽位：覆盖当前启用参数，并立即按新参数计量。

样本数量、容量范围、最大误差、启动阶段时长等诊断值只写入参数槽创建说明，不作为可编辑结构化参数保存。

## 持久化与迁移

配置版本升级时，旧配置中的可识别计量值迁移到参数槽 1，并将参数槽 1 设为当前启用槽位。旧候选若存在，也迁移为新候选参数，并把样本诊断值写入候选说明。

迁移后配置只保存新参数槽和候选字段，不继续保存旧计量字段。

## 页面边界

Web 只提供校准、保存候选、编辑参数槽和查看记录能力，不提供任何远程出水控制能力。

历史记录、容量预设等有明确水量上下文的位置可以显示对应 P/L 诊断值；没有水量上下文的独立平均值不得作为系统参数显示或保存。

## 1. 按键定义
### 1.1 按键时长定义
| 操作类型 | 触发时长 | 说明 |
|----------|----------|------|
| 短按 | < 1s | 普通操作、确认 |
| 长按 | 1~3s | 返回、强制重启（红键） |
| 组合长按 | 红键+绿键同时按住 > 5s | 恢复出厂设置（防误触的安全操作） |

### 1.2 各按键功能定义
#### 红键（紧急停止键，优先级最高）
| 场景 | 短按功能 | 长按（1~3s）功能 |
|------|----------|----------|
| 所有场景 | 立即关阀，终止所有任务，返回空闲状态 | 关阀 + 强制重启设备 |

> **红键 ISR 架构说明**（与 DOC-03 §8.4 一致）：
> 红键按下瞬间（下降沿）ISR 立即触发，通过 `g_emergency_sem` 唤醒 ControlTask 执行关阀，
> 关阀响应 ≤50ms，**不受长按逻辑影响**。
> 长按时长（1~3s）由 InputTask 在主循环中计时判断（记录按下时刻，松开时计算时长），
> 通过 `g_input_queue` 发送 `INPUT_RED_LONG` 事件触发强制重启。
> 因此关阀是无条件立即执行的，重启是**松开键后**额外触发的后续动作。

#### 组合键操作
| 组合方式 | 按住时长 | 功能 | 触发时机 |
|---------|---------|------|---------|
| 红键 + 绿键同时按住 | > 5s | 恢复出厂设置，所有参数重置为默认值 | 双键均处于按下状态满 5s 后立即触发，无需松开 |

> **组合键实现说明**：
> 红键按下瞬间 ISR 照常触发关阀（≤50ms）。
> InputTask 同时检测红键物理状态（非 ISR，轮询引脚电平）和绿键状态：
> 若两键同时处于按下状态持续 ≥5s，则向 `g_input_queue` 发送 `INPUT_COMBO_FACTORY_RESET` 事件。
> 此设计保证了：①关阀实时性不受影响；②5s 双键组合防止日常误触；③无需等待松开即可触发。

#### 绿键（功能/确认键，高频操作专用）
| 场景 | 短按功能 | 长按功能 |
|------|----------|----------|
| 空闲状态 | 进入预设选择界面，快速启动常用出水 | 无 |
| 二次确认界面 | 确认启动出水 | 取消出水操作 |
| 出水状态 | 暂停/继续出水 | 立即停止出水 |
| 菜单界面 | 确认选中项、进入下级菜单、保存修改 | 返回上级菜单 |
| 异常状态 | 确认错误提示，返回空闲状态 | 无 |

#### EC11旋转编码器
| 操作 | 所有场景功能 |
|------|--------------|
| 顺时针旋转 | 数值加、切换下一个菜单项/预设 |
| 逆时针旋转 | 数值减、切换上一个菜单项/预设 |
| 中键短按 | 进入主菜单、确认选中项 |
| 中键长按 | 返回上级菜单、退出当前界面 |

## 2. 显示屏界面（0.91寸 IIC OLED 128x32）
### 2.1 通用显示规则

**像素布局**：屏幕总像素 128×32，纵向分两行：
- **第一行（上20px）**：大字体，使用 16px 高字体，英文/数字字符宽 10px，最多显示 12 个字符（12×10=120px，含间距）
- **第二行（下12px）**：小字体，使用 8px×8px 字体，最多显示 16 个字符（16×8=128px）
- **右上角状态图标（第一行末）**：占用末尾 3 个大字符位（30px），显示 2~3 个 ASCII 字符图标

**状态图标对照**：

| 状态 | 图标 | 含义 |
|------|------|------|
| SYS_IDLE | `·` | 空闲（单点，最简占位） |
| SYS_RUNNING | `>>` | 出水中 |
| SYS_PAUSED | `||` | 已暂停 |
| SYS_ERROR | `!!` | 错误 |
| SYS_SLEEP | 屏幕关闭 | 见 §2.8 |
| WiFi 未连接 | `W?` | 叠加显示在第二行末 |

**字体选用原则**：
- 第一行核心数值只显示 **数字、字母、`.`、`/`、空格**，不显示完整中文（避免超宽）
- 辅助说明文字统一使用第二行小字体
- 示例：出水时第一行只显示 `5.2L  03:15`（10字符 ✓）而非 `剩余5.2L / 03:15`（超宽 ✗）

| 1（默认页） | 累计出水量: 123.4L | 今日: 5.6L |

#### 出水二次确认界面

| 第一行（大字体） | 已暂停 | 居中闪烁显示 |
| 第二行（小字体） | 按绿键继续，5分钟后自动停止 | 显示倒计时 |

#### 异常/错误界面
| 行 | 内容示例 | 说明 |
|----|------|------|
| 第一行（大字体） | `E01  !!` | 错误代码：E01=无流量、E02=流量异常、E03=电磁阀故障、E04=存储错误 |
| 第二行（小字体） | `No flow 3s stop` | 显示具体错误原因（英文，避免中文超宽） |

> **注意**：网络异常（WiFi断开）**不触发**错误界面，属于后台自动重连的软降级，
> 仅在空闲界面第二行末尾追加 `W?` 状态图标提示。系统仍保持 SYS_IDLE 状态正常运行。

#### 休眠状态（SYS_SLEEP）
| 状态 | OLED 行为 | 说明 |
|------|-----------|------|
| 进入 SLEEP | 屏幕立即关闭（亮度=0） | 节省功耗，无任何显示 |
| SLEEP 中 | 屏幕保持关闭 | 任何按键或网络请求触发唤醒 |
| 唤醒后 | 恢复进入 SLEEP 前的界面（空闲待机界面） | 延迟 ≤100ms 重新点亮 |

#### OTA升级界面
| 行 | 内容示例 | 说明 |
|----|------|------|
| 第一行（大字体） | `OTA...  >>` | 居中显示，状态图标 `>>` |
| 第二行（小字体） | `45%  do not power off` | 进度百分比 + 警告提示（英文，避免超宽） |

## 3. 蜂鸣器反馈定义
| 蜂鸣器提示 | 对应状态 |
|------------|----------|
| 短嘀（100ms） | 操作确认有效、按键按下反馈 |
| 长嘀（500ms） | 出水完成、操作成功、重启提示 |
| 三短嘀（100ms×3） | 操作无效、参数错误、异常触发 |
| 长鸣（持续） | 严重错误、报警状态（后续扩展漏水检测功能使用） |

## 4. Web 管理界面
### 4.1 路由表
| 路径 | 页面功能 |
|------|----------|
| `/` | 首页：实时状态显示、快速出水控制、操作按钮 |
| `/logs` | 日志查询页面：支持分页、按时间范围过滤、导出 |
| `/config` | 参数配置页面：所有系统参数可视化配置 |
| `/statistics` | 用水统计页面：日/周/月/年/累计用水量图表展示 |
| `/filters` | 滤芯管理页面：滤芯状态查看、寿命重置、参数配置 |
| `/calibrate` | 流量校准页面：可视化校准工具，引导用户完成流量校准 |
| `/ota` | OTA升级页面：固件上传、升级进度显示 |
| `/help` | 帮助页面：操作说明、故障排查指南 |

### 4.2 鉴权方式
所有页面和 API 都强制启用 **HTTP Basic Auth** 认证：
- 默认用户名：`admin`
- 默认密码：`admin`（首次使用强烈建议修改）
- 密码**明文存储**在 NVS 中（ESP32 NVS 本身无硬件加密，了解这一点后自行评估风险），重启不丢失
- 无会话超时，重启后浏览器需要重新认证

> **CORS 说明**：Web 页面与 API 均由设备本身提供服务（同源），**不开启 CORS**。
> 若开启 CORS 并同时使用 Basic Auth，浏览器的 OPTIONS 预检请求不携带认证头，
> 会导致请求失败。如需第三方页面调用 API，须在同一局域网直接访问设备 IP。

### 6.2 日志格式
```
[时间戳] [级别] [模块] 描述内容
```
| 字段 | 说明 |
|------|------|
| 时间戳 | 格式：`YYYY-MM-DD HH:MM:SS`，无RTC时显示相对时间 |

## 设计审查说明
### 1. 状态定义清晰度
✅ 所有交互反馈定义明确，蜂鸣器+屏幕显示双重提示，不同状态无歧义：
- 按键操作有即时蜂鸣反馈+屏幕刷新
- 异常状态有错误代码+三短嘀报警
- 不同操作类型的反馈区分清晰，不会混淆

### 2. 操作反馈覆盖度
✅ 所有用户操作都有对应反馈，无遗漏：
- 本地按键操作：蜂鸣器即时响应+屏幕同步刷新
- Web端操作：JSON返回操作结果+设备端同步状态更新
- 系统事件：弹出提示界面+对应蜂鸣器提示
- 异常事件：错误代码显示+报警音提示

### 3. OLED界面适配性
✅ 界面设计完全适配128x32窄屏：
- 核心信息大字体突出显示，重点内容一眼可见
- 辅助信息简洁明了，无冗余内容
- 菜单层级浅（最多3级），操作逻辑简单，学习成本低
- 所有状态提示文字通俗易懂，无专业术语

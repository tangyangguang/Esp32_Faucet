# 变更记录

## 2026-06-17 当前实现收口

- 新增 ADS1115 作为传感器 ADC，A0 固定为 100K/10K 输入电压检测，A1 固定为 50K B3950 NTC 水温，A2 固定为 TDS Board V1.0 模拟输出，A3 预留外部 0-3.3V 模拟输入。
- MH-01 温度线按“一根绿色信号线 + 公共黑色 GND”的 NTC 接法设计，板上使用 51K 1% 上拉到 3.3V_A。
- 流量计仍按脉冲输入和计量方案校准支持，不增加流量计型号枚举；MH-01/YF-S201 等同类脉冲流量计通过重新校准适配。
- 新增水温、TDS、输入电压实时状态；水温和 TDS 可写入每条出水记录，并在统计中形成每日趋势。
- TDS 未校准时允许显示和记录，但 Web/记录必须标记未校准；校准支持普通单点和低值/高值两点流程，保存校准只写一次系统配置并递增校准版本。
- 系统设置里的水温和 TDS 传感器使用枚举选择，不暴露内部数字类型，也不让用户配置 ADS1115 参考电压。
- 顶层导航只保留“校准”。`/faucet/calibration` 直接展开流量计校准、温度校准、水质校准三块；`/faucet/calibration/flow` 作为隐藏入口承载流量校准流程、样本库、方案生成、手工方案管理、测算和显式启用。
- 校准页新增“水质校准”面板，两点校准作为主流程；温度校准从系统配置移到校准首页，用户输入参考温度后保存偏移。
- LCD1602 传感器待机页默认关闭；开启后只在待机状态轮播，不打断确认、运行、暂停、结果、报警和校准页面。
- 出水记录结构扩展到 64 字节并保存传感器摘要；当前测试阶段不做跨结构读取，文件头版本不匹配时通过明确格式化或重建处理。
- 系统配置只加载当前版本结构；无版本、非当前版本或不可识别版本按当前默认配置加载，显式保存时写入当前结构。
- 构建参数调整为 `ESP32BASE_APP_CONFIG_MAX_GROUPS=6`、`ESP32BASE_APP_CONFIG_MAX_FIELDS=64`，容纳新增传感器配置项并保留少量扩展余量。

# 流量计计量参数设计

本文定义流量计计量参数、校准会话和历史参数的当前模型。本文只描述当前设计，不保留旧版本兼容规则。

## 设计结论

- 普通流量校准只有一个主流程：Web 进入校准模式，本地按键完成出水/停止，Web 录入量杯实测容量。
- 当前校准会话至少 2 条有效样本后自动生成推荐参数，推荐 3 条，最多 6 条有效样本和 6 次尝试。
- 完整脉冲明细只用于页面查看图表和诊断；参数生成使用每条样本保存后的轻量摘要，不反复扫描完整明细。
- 不再维护长期样本库。查看历史典型出水过程的需求由当前/最近一次校准会话的样本明细满足。
- 保存推荐结果或手工设置参数时，创建一条新的当前参数记录；旧当前参数自然成为历史参数。
- 历史参数固定最多 6 条，不提供原地编辑、删除或恢复入口。满 6 条后，新建参数覆盖最早的非当前参数；页面允许复制历史参数作为手工设置表单的初始值，保存后仍创建新参数 ID。
- 出水记录只保存当时使用的参数 ID，不保存 5 个参数快照。过久记录如果对应参数已被覆盖，页面显示历史参数不可查看。

## 命名

页面和文档统一使用以下名称：

- 流量计计量参数：设备把脉冲换算成水量时使用的一组参数。
- 当前参数：设备正在用于出水估算的唯一参数。
- 历史参数：曾经保存过但当前未使用的参数记录。
- 系统内置默认参数：首次启动或参数文件缺失时由系统创建的兜底参数。
- 推荐参数：根据当前校准会话样本自动生成、尚未保存的临时结果。
- 手工设置参数：用户在 Web 页面输入 5 个计量参数后保存的新当前参数。
不使用“高级诊断”“长期样本库”“方案槽位”“逻辑删除”“usedEver”等作为用户概念。

## 计量参数

每条参数记录只保存 5 个真正参与估算或展示的参数。

容量估算参数用于根据有效脉冲估算实际出水容量：

- 启动脉冲数 `Ns`
- 启动水量 `Vs`
- 稳态 P/L `Ps`

容量估算公式：

```text
P = 0:
  V = 0

0 < P <= Ns:
  V = round(P * Vs / Ns)

P > Ns:
  V = Vs + round((P - Ns) * 1000 / Ps)
```

`Ns = 0` 且 `Vs = 0` 时，启动段等价于没有，全部有效脉冲按稳态 P/L 计算。

时间估算参数只用于预计展示：

- 启动时长 `Ts`，单位 ms。
- 预计稳态流速 `Fs`，单位 ml/min。

时间估算参数只用于预设、确认页、测算工具等位置的预计展示，不参与实际出水容量、滤芯累计或统计累计。任何实际容量都必须由容量估算参数按有效脉冲计算；异常出水或 0 脉冲不能用时间估算补容量。

目标容量预计时间：

```text
Ts = 0 或 Vs = 0:
  T = V * 60000 / Fs

V <= Vs:
  T = V * Ts / Vs

V > Vs:
  T = Ts + (V - Vs) * 60000 / Fs
```

给定时间预计容量：

```text
Ts = 0 或 Vs = 0:
  V = T * Fs / 60000

T <= Ts:
  V = T * Vs / Ts

T > Ts:
  V = Vs + (T - Ts) * Fs / 60000
```

## 参数记录

每条历史参数记录保存：

- `id`：稳定 ID，创建后不复用。
- `recordUsed`：底层槽位是否占用，仅作为存储层状态。
- `name`：参数名称。
- `startupPulseCount`：启动脉冲数。
- `startupVolumeMl`：启动水量，单位 ml。
- `stablePulsePerLiter`：稳态 P/L。
- `startupDurationMs`：启动时长，单位 ms，仅用于预计展示。
- `stableFlowMlPerMin`：预计稳态流速，单位 ml/min，仅用于预计展示。
- `sourceType`：`default`、`calibration_session`、`manual`。
- `createdAt`：创建时间。

如果参数来自校准会话，额外保存最小生成摘要：

- `sampleCount`：生成时使用的有效样本数量。
- `minActualMl`：生成样本中的最小实测水量。
- `maxActualMl`：生成样本中的最大实测水量。
- `maxErrorMl`：生成拟合后的最大绝对误差。
- `maxErrorTenthPercent`：生成拟合后的最大相对误差，使用整数十分之一百分比保存。

参数记录不保存参与样本 traceId 数组、完整脉冲明细、启动阶段分布统计、长篇备注、最近修改时间、修订号、精确使用次数或 usedEver 标记。这些信息不参与运行计量，保留会增加 Flash 常驻数据、页面复杂度和更新流程。

## 历史参数规则

系统必须始终有且只有一条当前参数。

系统内置默认参数：

- 名称：`YF-S201 默认计量方案`。
- 启动脉冲数：`8P`。
- 启动水量：`130ml`。
- 稳态 P/L：`248P/L`。
- 启动时长：`5000ms`。
- 预计稳态流速：`1950ml/min`。
- 来源：系统内置默认参数。

参数文件固定 6 槽：

- 槽位未满时，新参数使用空槽。
- 槽位已满时，新参数覆盖最早的非当前参数。
- 当前参数不被覆盖。
- 新参数 ID 继续递增，不复用被覆盖参数的 ID。
- 如果极端情况下文件中只有当前参数、且没有空槽或可覆盖项，保存失败并提示存储不可用；正常 6 槽文件不会出现这种状态。

历史参数不可原地编辑、不可删除，也不能被直接切换或恢复为当前参数。当前参数通过“应用本次校准推荐参数”或“保存手工设置参数”改变；复制历史参数只用于预填表单，保存后必须创建新参数 ID。

## 校准会话样本

校准会话样本分两层保存：

- 会话记录：保存样本状态、实测容量、出水记录身份和轻量摘要。
- 会话明细：Flash 固定 6 槽，保存当前或最近一次校准会话的完整脉冲明细，用于页面图表和诊断查看。

新会话复用会话明细槽位。退出校准状态后，页面仍可以查看最近一次会话样本和脉冲明细；再次开始新会话后，旧明细可被覆盖。

轻量摘要包含生成参数需要的信息：

- 实测容量。
- 总脉冲、过滤脉冲、出水时长。
- 是否截断、是否暂停后恢复。
- 稳态识别是否成功。
- 启动段脉冲、稳态脉冲、稳态开始时间、稳态脉冲频率。
- 是否可用于生成参数。

参数生成只读取会话记录里的轻量摘要。完整脉冲明细只在用户打开详情图表时读取。

## 推荐参数生成

系统只使用容量已录入、未截断、未发生暂停后恢复、有效脉冲大于 0 且稳态识别成功的样本生成推荐参数。

生成门槛：

- 有效样本数量不少于 2 条。
- 推荐样本数量为 3 条。
- 最大实测水量和最小实测水量差值不少于 500ml。
- 最大绝对误差不超过 100ml，最大相对误差不超过 5%。

质量门槛不满足时，页面只显示诊断原因，不能保存推荐参数。

推荐参数是临时结果：可以保存在 RAM 或会话状态中，不作为独立长期 Flash 数据。用户保存后，系统创建新的当前参数记录，并写入最小样本摘要。

## 页面结构

流量计校准中心按任务分区：

1. 当前参数
   - 显示当前参数名称。
   - 显示 5 个计量参数，并区分容量估算参数和时间估算参数。
   - 明确提示时间估算参数只用于预计展示，不参与实际容量、滤芯累计或统计累计。
   - 显示来源、创建时间和最小样本摘要。

2. 校准流程
   - 进入校准模式只改变设备校准状态，不提供网页启动出水。
   - 本地只负责 `OK` 开始校准出水和 `CANCEL` 停止校准出水。
   - 校准出水不使用当前预设目标，不按预设容量或预设时长自动结束。
   - 每次校准出水停止后，在网页录入量杯实测容量。
   - 至少 2 条有效样本后自动刷新推荐参数；新增有效样本或放弃当前待录入样本后刷新页面状态。

3. 保存当前参数
   - 当前推荐参数保存后，创建一条新的历史参数记录并设为当前。
   - 手工设置参数保存后，同样创建一条新的历史参数记录并设为当前。
   - 原当前参数保留为历史参数。

4. 历史参数
   - 列表显示最多 6 条参数记录。
   - 当前参数有明确标记。
   - 每条记录显示名称、参数摘要、来源、创建时间和最小样本摘要。
   - 不显示原地编辑、删除、恢复、使用次数或 usedEver 状态。
   - 可以复制某条历史参数进入手工设置表单；保存后创建新当前参数，不修改被复制的历史记录。

5. 样本明细
   - 展示当前或最近一次校准会话的样本。
   - 样本详情页读取完整脉冲明细并显示图表。
   - 明细不参与常规页面刷新和参数生成的重复计算。

校准首页只承担状态概览和入口：展示当前计量参数、温度状态和水质状态，并进入流量计校准中心、温度校准详情和水质校准详情。

## 存储策略

流量计计量参数从 `SystemConfig` 中拆出，使用独立的 `MeteringSchemeStore` 管理。

`SystemConfig` 继续保存安全阈值、显示、蜂鸣器、滤芯、预设等系统配置。流量计计量参数独立保存：

- 参数存储版本。
- 当前参数 ID。
- 下一个参数 ID。
- 6 条定长参数记录。

保存参数时只写入新的参数记录和必要索引，不重写整个系统配置。普通出水完成后不更新参数记录，避免高频 Flash 写入。

会话样本使用独立存储：

- RAM：保留当前/最近一次完整脉冲明细缓存。
- 会话明细文件：Flash 固定 6 条完整明细，新会话可覆盖上一会话。
- 会话记录文件：保存样本状态和轻量摘要，供页面刷新和参数生成使用。

长期样本库不再作为独立存储域存在。

## 出水记录追溯

每条成功生成的出水记录必须保存当时使用的参数引用：

- `meteringSchemeId`

出水记录不保存 `startupPulseCount`、`startupVolumeMl`、`stablePulsePerLiter`、`startupDurationMs`、`stableFlowMlPerMin` 等完整参数快照。历史追溯由参数记录承担：如果用户通过校准改变参数，必须创建新的参数 ID。参数文件固定 6 槽，槽位满后系统覆盖最早的非当前参数；被覆盖参数对应的早期历史记录显示“历史参数不可查看”。

## 文案原则

- 普通用户界面只使用“当前参数”“推荐参数”“历史参数”，减少“方案管理”感。
- 不使用“高级诊断”“长期样本库”“辅助计算”作为流量校准主流程概念。
- 不使用“覆盖当前方案”作为推荐结果保存动作。
- 所有会影响当前计量的操作必须显式提示。
- 历史参数不显示原地编辑、删除或恢复入口；当前参数变化来自应用本次校准推荐参数或保存手工设置参数。
- 每套参数必须分组显示“容量估算参数”和“时间估算参数”。
- 页面必须明确“时间估算参数只用于预计展示，不参与实际容量、滤芯累计或统计累计”。
- “实时流速”“预计流速”“平均流速”必须区分显示，不混用。
- 样本依据只以最小摘要永久保留。

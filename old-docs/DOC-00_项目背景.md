# 项目背景

## 项目概述
本项目是基于ESP32单片机开发的净水器智能出水龙头，主要解决家用净水器接水时需要人工值守、容易忘记关水导致溢出的痛点。
家里现有净水器出水速度较慢，接满1.5升水壶需要1-2分钟，接满7.5升大水桶需要5-6分钟，接水过程中如果人在旁边等待浪费时间，离开又容易忘记导致水溢出。因此开发这款智能龙头实现接满自动停止功能，解放人力，避免溢水风险。
设备兼具本地操作和web管理能力，常用功能通过物理按键和显示屏完成，完整的数据分析和系统配置通过网页界面实现。

## 应用场景
- 安装位置：家庭厨房厨下空间，与现有净水器水路串联安装
- 使用人群：普通家庭成员，无需专业操作技能
- 使用频率：家庭日常使用，每天1-3次
- 主要使用场景：
  1. 核心场景：接7.5升大水桶，占绝大部分使用比例
  2. 次要场景：接1.5升水壶或其他临时容量的小场景

## 设计考量与约束
- 硬件约束：核心硬件（ESP32单片机、12V常闭电磁阀、YF-S201霍尔水流量计、0.91寸IIC OLED 12832显示屏、EC11旋转编码器）已经采购，均为标准型号，按通用方案开发即可；支持DS3231实时时钟模块（可选焊接，软件兼容）
- 供电方案：厨下安装，采用220V市电转12V供电
- 可靠性要求：需要7*24小时不间断运行，具备异常自动保护能力
- 技术选型约束：采用Arduino框架开发，使用FreeRTOS多任务系统保障实时性
- 安全性约束：电磁阀为常闭型，断电时默认关水，避免异常情况下漏水
- 操作约束：常用功能必须可以通过本地按键和显示屏完成，无需依赖网络

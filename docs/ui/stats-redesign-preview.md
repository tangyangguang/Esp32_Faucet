# 统计页视觉预览

`stats-redesign-preview.html` 是统计页重设计的冻结视觉稿，用于后续讨论和迭代统计页布局、文案、配色、字重、圆角和图表细节。

使用方式：

- 直接用浏览器打开 `docs/ui/stats-redesign-preview.html`。
- 后续若要调整统计页视觉，优先修改这份预览，再同步到固件页面实现。
- 预览中的数据是示例数据，不代表设备真实统计。

当前冻结口径：

- 顶部四张卡展示今日、本月、过去 30 天日均和总累计。
- 主图展示最近 30 天每日出水量，次数使用低存在感折线作为辅助趋势。
- 柱顶升数标签不重复加 `L`；次数标签只上下避让升数标签，不左右偏移。
- 底部分布固定为最近 30 天真实时间记录，包含按预设分布、按容量段分布、按完成结果分布。

## 1. 项目背景

**设备用途**：安装于家庭厨房厨下净水器的智能控水设备，实现定量/定时出水自动停止、漏水报警、异常流量保护、多滤芯寿命提醒等功能，解决接水时需要人工值守、容易忘记关水导致溢水的痛点，主要满足7.5L大桶接水和1.5L水壶接水场景。

**使用者**：普通家庭成员，无专业技能要求，日常使用频率每天1-3次。

**参考调研**：RES-01 同类设备调研、RES-02 用户痛点与优点分析、RES-03 YF-S201流量计专项调研

## 4. 硬件约束

- **芯片**：ESP32-WROOM-32（4MB Flash版本）
- **Flash分区表**：高冗余4MB分区方案：64KB配置区 + 1.4MB*2 OTA分区 + 1.1MB LittleFS文件系统，余量充足；LittleFS断电保护更强、小文件读写更快、磨损均衡更优，适配20000条日志存储需求
- **GPIO**：预留≥12个可用GPIO，已占用引脚根据硬件设计确定
- **电源**：220V市电转12V 2A适配器，12V转5V给ESP32和外设供电
- **工作环境**：温度0-60℃，相对湿度≤95%（无凝结），电路板做三防漆处理
- **已确定硬件**：2分常闭电磁阀（通电开、断电关）、IRLR7843 MOS管驱动、SS34续流二极管、YF-S201霍尔流量计、0.91寸IIC OLED 12832、EC11旋转编码器、红/绿独立按键、5V无源蜂鸣器、可选DS3231 RTC模块；硬关阀通过外部串联12V船型开关实现

## 6. 边界

**不在范围内**：语音控制、原生手机APP、多设备联动、云平台接入、TDS水质检测（当前版本）

**已知限制**：
1. YF-S201流量计在流量<1L/min时精度误差≤±20%，属于传感器固有特性
2. 厨下WiFi信号弱时可能出现连接不稳定，不影响本地功能
3. 设备本身不具备机械旁路功能，故障时需要用户手动切换旁路阀门
4. 无DS3231硬件RTC时，断网后时间会丢失，重新联网后自动同步

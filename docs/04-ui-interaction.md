# UI 与交互草案

## 当前已确认原则

- 本地输入使用四个功能按键：`CANCEL`、`OK`、`PLUS`、`MINUS`，面板标注建议使用“取消 / 确认 / 加 / 减”。
- 不使用颜色命名按键。
- 本地交互优先支持高频操作和软件停止兜底。
- 复杂配置优先放到 Web，避免本地菜单过重。

## 按键语义

- `CANCEL`：取消、返回；出水中按下立即停止并关阀。
- `OK`：确认、启动、暂停/继续。
- `PLUS`：待机选择下一个预设；确认页按 Web 配置步进增加本次目标值。
- `MINUS`：待机选择上一个预设；确认页按 Web 配置步进减少本次目标值。
- `OK` 长按：确认页和暂停页不切换步进；结果页按住超过 5 秒进入现场校准。

## 状态交互

### 待机

- `PLUS` 短按：切换到下一个启用预设。
- `MINUS` 短按：切换到上一个启用预设。
- `OK` 短按：进入当前预设的二次确认。
- `CANCEL` 短按：确保关阀并保持待机，不记录出水记录。

### 二次确认

- `OK` 短按：开始出水。
- `CANCEL` 短按：取消并返回待机。
- `PLUS` / `MINUS` 短按：调整本次目标值，不修改预设；容量默认步进 0.10L，时间默认步进 10s，步进值可在 Web 后台配置。
- 10 秒无操作：自动取消。

### 出水中

- `CANCEL` 按下瞬间：立即关阀，返回待机或错误提示，优先级最高。
- `OK` 短按：暂停。
- `PLUS` / `MINUS` 短按：无动作，避免运行中误改目标。

### 暂停

- `OK` 短按：继续出水。
- `CANCEL` 短按：停止任务并进入结果显示。
- `PLUS` / `MINUS` 短按：无动作，避免暂停后误改容量或时间目标。
- 超过暂停超时时间：自动停止并记录暂停超时。

### 结果显示

- 正常完成、用户停止、暂停超时、安全停止或流量异常后显示本次结果，默认 30 秒，Web 可配置，0 表示不显示。
- `OK` 或 `CANCEL`：立即回到待机。
- `PLUS` / `MINUS`：立即回到待机并切换预设。
- `OK` 按住超过 5 秒：基于本次出水原始脉冲进入现场校准，触发时立即进入，不等松开。

### 现场校准

- 入口：只从结果页 `OK` 按住超过 5 秒进入。
- `PLUS` / `MINUS`：按当前步进调整量杯实际水量。
- `OK` 短按：保存校准系数。
- `OK` 长按：切换实际水量步进 0.10L / 0.01L。
- `CANCEL`：放弃并返回结果页。

### 本地菜单边界

当前固件不实现通用多级本地菜单；本地只保留常用出水、暂停/继续、停止和确认页本次目标值调整。预设、滤芯、WiFi、OTA、校准参数、恢复出厂等复杂操作放 Web 或 Esp32Base 系统页面。

## LCD1602 页面草案

| 页面 | 第一行 | 第二行 |
| --- | --- | --- |
| 待机容量 | `SEL P1 1.5L 450P` | `TODAY 1.23L` |
| 待机时间 | `SEL P2 60s 450P` | `TODAY 1.23L` |
| 确认容量 | `GO P1 1.5L 450P` | `STEP 0.10L` |
| 确认时间 | `GO P2 60s 450P` | `STEP 10s` |
| 运行容量 | `RUN 00:12 450P` | `0.35L LFT 0.65L` |
| 运行时间 | `RUN 00:12 450P` | `0.35L LFT 48s` |
| 暂停 | `PAU 0.35L 450P` | `CAN=STOP OK=RUN` |
| 完成 | `Done 7.50L 450P` | `Hold OK Cal` |
| 用户停止 | `Stopped 3.30L` | `Hold OK Cal` |
| 校准 | `A1.00L 450P` | `S0.10 +/- OK` |
| 错误 | `Error 450P` | `Flow Error` |

LCD1602 只有 16 字符宽，文案优先使用短英文、数字和固定缩写，避免中文过宽和频繁换页。所有醒屏页面第一行右侧固定显示每升脉冲数，例如 `450P`；本地 LCD 不显示预设名称，只显示预设编号和容量或时间。

## Web 页面草案

- 首页：卡片式显示当前状态、当前预设、基础统计和启用滤芯寿命进度。
- 配置：阈值、蜂鸣器、显示、安全参数、本地确认页调整步进和启动补偿水量。
- 预设：9 组预设的启用、名称、类型和值；名称最多 15 个字符。
- 记录：分页查询，紧凑显示开始时间、目标值、出水量、持续时间、预设模式、结束原因、脉冲/P-L、校准状态和操作。过滤脉冲属于低频诊断信息，只在有值时显示在脉冲单元格小字里；已校准记录在出水量单元格小字显示实测水量，最新已校准记录操作为“重校”。
- 统计：今日、本周、本月、总累计。
- 滤芯：最多 6 个滤芯的已用天数、已用流量、寿命范围、状态、独立设置入口和重置入口。
- 校准：主流程基于最后一次本地真实出水记录的原始脉冲数计算，也保留高级手动保存每升信号数；Web 不允许远程启动出水。
- OTA：使用 Esp32Base 内置页面。

Web 页面不得提供启动出水、暂停出水、继续出水或停止出水入口。

### Web 滤芯交互

- 滤芯页只显示列表，便于快速查看每级滤芯状态、已用天数、已用流量和寿命设置。
- 每级滤芯提供“设置”入口，进入独立编辑页后再修改启用状态、名称、建议更换周期、最长使用周期、寿命流量、上次更换日期。
- 寿命周期以月输入，按 30 天/月保存；建议更换周期用于“建议更换”，最长使用周期用于“已超期”。
- 寿命流量以 ml 输入，并在输入框下方显示 L，页面展示默认使用 L 且保留 2 位小数。
- 上次更换日期使用浏览器日期选择控件，提交值仍按 `YYYY-MM-DD` 校验；有效日期范围为 2020-2099，保存后作为已用天数的起点。
- 保存或取消后返回滤芯列表页，避免低频配置表单占用列表页空间。
- 重置需要二次确认，提交后清零该级滤芯累计流量、更新更换时间，并返回滤芯列表页。

## 已确认事项

- 本地只允许在确认页调整本次出水目标，不修改当前预设配置；暂停页不允许调整目标。
- 出水中 `OK` 短按用于暂停，`CANCEL` 用于停止。
- Web 端不允许任何出水控制。

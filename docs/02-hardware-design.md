# 硬件设计草案

## 当前已确认原则

- 主控目标为 ESP32-WROOM-32 4MB。
- 输入设备使用四个独立功能按键，命名为 `CANCEL`、`OK`、`PLUS`、`MINUS`。
- 硬件设计优先服务安全关阀、日常盲操作、稳定运行和易维护。
- 电磁阀必须为常闭型，软件失效或断电时默认关水。
- 外部电源开关作为硬件停止手段，不属于软件控制范围。

## 硬件范围草案

| 模块 | 策略 |
| --- | --- |
| 主控 | ESP32-WROOM-32 4MB |
| 电磁阀 | 12V 常闭电磁阀，MOS 控制，支持全压吸合 + PWM 保持 |
| 流量计 | 脉冲式霍尔流量计，中断计数；MH-01/YF-S201 等同类型号通过校准计量方案适配 |
| 传感器 ADC | ADS1115，I2C 地址 0x48；A0 输入电压，A1 水温，A2 TDS，A3 预留 |
| 水温 | MH-01 50K B3950 NTC，板上 51K 1% 上拉分压 |
| TDS | MH-01 红蓝电极线接外部 TDS Board V1.0，模块 AO 接 ADS1115 |
| LCD | LCD1602 I2C 显示屏，PCF8574T 背包，默认地址 0x27 |
| 按键 | `CANCEL`、`OK`、`PLUS`、`MINUS` 四个独立按键，低电平有效，软件启用内部上拉，硬件仍建议预留外部 10K 上拉 |
| 蜂鸣器 | 5V 无源蜂鸣器，PWM 控制，可 Web 开关 |
| RTC | DS3231 自动检测支持；未焊接时软件降级 |
| 漏水检测 | 不做 |

## GPIO 草案

| GPIO | 功能 | 说明 |
| --- | --- | --- |
| GPIO16 | 电磁阀控制 | 输出，避开 ADC2，支持 PWM |
| GPIO32 | 流量计脉冲 | 输入中断，WiFi 可用；软件启用内部上拉，硬件仍建议外部上拉/电平转换 |
| GPIO33 | `CANCEL` | 输入中断，启用内部上拉；出水中最高优先级软件停止关阀 |
| GPIO25 | `OK` | 输入，启用内部上拉；确认/启动/暂停继续 |
| GPIO26 | `PLUS` | 输入，启用内部上拉；切换下一个预设或增加本次目标水量 |
| GPIO27 | `MINUS` | 输入，启用内部上拉；切换上一个预设或减少本次目标水量 |
| GPIO17 | 蜂鸣器 PWM | 输出 |
| GPIO21 | I2C SDA | LCD1602、DS3231、ADS1115 |
| GPIO22 | I2C SCL | LCD1602、DS3231、ADS1115 |
| ADS1115 A0 | 输入电压检测 | VIN 通过 100K/10K 1% 分压，软件按 11:1 换算 |
| ADS1115 A1 | 水温检测 | 51K 1% 上拉到 3.3V_A，MH-01 绿色温度线通过内部 50K B3950 NTC 到公共 GND |
| ADS1115 A2 | TDS 检测 | TDS Board V1.0 AO，模块 3.3V 供电 |
| ADS1115 A3 | 外部预留 | 0-3.3V analog only，第一版软件不启用 |
| GPIO1 | UART0 TX | 调试串口 |
| GPIO3 | UART0 RX | 调试串口 |

GPIO34、GPIO35、GPIO36、GPIO39 暂不使用，保持未分配，避免使用无内部上拉能力的输入脚承载按键。

## 安全与可靠性要求

- `CANCEL` 使用可中断输入，按下瞬间触发软件停止关阀路径。
- 外部硬断电开关只作为硬件电源开关事实存在，软件不检测、不控制、不建模。
- 电磁阀驱动必须有续流二极管，MOS 选型留足电流余量。
- 流量计输入需要硬件上拉和基础滤波，软件再做脉冲间隔过滤。
- 裸板或未接流量计时 GPIO32 不应悬空；当前软件启用内部上拉以降低误触发，但实机接线仍以稳定外部上拉和 3.3V 电平为准。
- MH-01 黄色流量脉冲建议先经施密特触发器整形和电平转换，再接 GPIO32；软件只按 3.3V 脉冲输入处理。
- MH-01 绿色温度线不是主动模拟电压输出，必须通过板上固定电阻分压后进入 ADS1115 A1。默认接法为 3.3V_A -> 51K 1% -> TEMP_AO -> 传感器内部 NTC -> GND。
- MH-01 红蓝 TDS 线只是电极线，必须接外部 TDS 模块探针接口；不得直接接 ADS1115 或 ESP32。
- ADS1115 A0/A1/A2 前建议串 1K 保护电阻，采样点对 GND 放 100nF；模拟走线远离电磁阀 PWM、蜂鸣器 PWM、流量脉冲和 12V 执行器线。
- 强电、12V 执行器和 3.3V 控制信号布线保持隔离和单点共地。
- 未使用接口不参与软件逻辑，避免影响稳定性。

## 已确认实现决策

- `CANCEL` 使用 GPIO33，`OK` 使用 GPIO25，`PLUS` 使用 GPIO26，`MINUS` 使用 GPIO27。
- `CANCEL`、`OK`、`PLUS`、`MINUS` 四个按键均启用 ESP32 内部上拉，低电平有效；硬件仍建议预留外部 10K 上拉以增强抗干扰。
- ADS1115 默认焊接使用，ADDR 接 GND，地址 0x48；A0/A1/A2 分别固定为输入电压、水温和 TDS，A3 只预留。
- 水温硬件默认只支持 50K B3950 NTC + 51K 上拉；如果实物测得绿色温度线到黑色 GND 不是室温约 40K-70K，应暂停上板并重新确认传感器内部接法。
- GPIO34-39 无内部上拉能力，后续不得分配给需要内部上拉的按键输入。

# 配置持久化说明

本文定义当前固件的业务配置、运行统计和滤芯运行量持久化规则。

## 系统业务配置

- 系统业务配置保存在 `faucet_cfg` namespace。
- `ConfigStore` 只读取版本号等于当前固件支持版本的配置。
- 无版本、非当前版本或不可识别版本一律返回当前默认配置；加载过程不探测旧字段、不合并旧字段、不写回版本号。
- 用户在 Web 或 Esp32Base AppConfig 保存配置时，系统按当前结构重新写入完整配置，并最后写入当前版本号。
- 保存失败时不更新版本号，避免半写入数据被下一次启动当作完整当前配置读取。

## 独立持久化域

- 运行统计保存在 `faucet_stat` namespace，只保存可重建的统计计数和周期键。
- 滤芯运行量保存在 `faucet_run` namespace，只保存用量和启动 boot id；滤芯名称、寿命和启用状态属于系统业务配置。
- 流量计计量方案使用独立 LittleFS 文件保存，避免频繁调整计量方案时整块重写系统配置。
- 出水记录、记录校准元数据、校准样本和计量方案文件都有自己的文件头、版本和校验规则；版本或结构不匹配时返回不可用状态，由测试阶段人工格式化或重建。

## 写入频率

- 系统业务配置只在用户提交配置、校准保存或明确重置时写入。
- 运行统计和滤芯运行量按实际出水结果写入，不在普通状态刷新中写入。
- 传感器实时值只用于显示和本次出水摘要，不直接高频写入配置区。

## 当前测试阶段原则

本项目用于新设备和上板测试，用户已明确可格式化数据。固件不为早期测试结构保留兼容分支；需要清理异常数据时，通过明确格式化 NVS/LittleFS 或重新保存当前配置完成。

# 原始脉冲明细设计

本文定义出水过程的原始脉冲明细设计。它是计量、校准、异常排查和后续分析的事实源，不保存按秒分桶后的派生结果。当前方案固定为 RAM 最近 1 条完整脉冲明细、校准会话样本区 3 槽、长期样本库 5 槽。

## 设计目标

- 原始明细必须尽可能客观表达硬件输入事实。
- 原始明细不直接保存“每秒几个脉冲”这类已经聚合、可能受边界影响的分析结果。
- 所有每秒统计、流速曲线、稳态识别、启动段识别和样本可用性判断，都从原始明细派生。
- 后续分析方法可以调整，但不应破坏或重写原始事实源。
- 用户查看的一条出水记录详情，和专业调试用的脉冲明细必须分开定位。

## 原始事实源

每条脉冲明细保存本次出水期间 ISR 捕获到的原始脉冲边沿时间：

```text
uint32_t elapsedUs[]
```

`elapsedUs` 表示该边沿距离本次出水开始的微秒数。单个脉冲不保存年月日时分秒，因为一次出水是连续时间段，内部时间轴应只依赖单调时间，不受 NTP 校时、时区或系统时间变化影响。

暂停/恢复不从脉冲低谷推断，而是作为操作状态事实单独保存：

```text
pauseWindows[] = {
  uint32_t startElapsedUs,
  uint32_t endElapsedUs
}
```

`startElapsedUs` 表示进入暂停的时间点，`endElapsedUs` 表示恢复出水、手动停止或暂停超时时关闭暂停区间的时间点。暂停后恢复出水的记录仍保存完整明细，但标记为多段出水，不参与启动段和分段校准拟合。

明细头部保存本次出水的业务元数据和判定配置快照，包括：

- 开始时间。
- 持续时间。
- 出水结果。
- 模式、目标、固件估算出水量。
- 总原始边沿数。
- 总有效脉冲数。
- 过滤边沿数。
- 当时使用的 `pulseMinIntervalUs`。
- 当时启用的计量方案 ID；如需查看计量参数，按方案 ID 查询对应方案记录。
- 暂停时间窗、暂停次数、暂停总时长、是否暂停后恢复出水、出水段数量。
- 是否截断。
- 实测出水量。

## 有效脉冲判定

原始边沿是否计入有效脉冲，是基于配置和算法的派生判定，不是原始事实本身。

默认判定规则：

- 第一个原始边沿判为有效。
- 后续边沿与上一个有效边沿的间隔大于等于 `pulseMinIntervalUs` 时，判为有效。
- 小于 `pulseMinIntervalUs` 的边沿判为过滤边沿，不参与实时计量和校准分析。

实时出水控制仍按当时配置执行有效脉冲判定，避免硬件毛刺影响出水量和停水判断。原始明细同时保存所有已捕获边沿，用于后续排查和重新分析。

## 配置

### `pulseMinIntervalUs`

最小有效脉冲间隔。默认先使用 `1000 us`，可配置范围先定为 `100-100000 us`。

页面必须同时显示等效最大有效频率：

```text
最大有效频率 = 1000000 / pulseMinIntervalUs Hz
```

示例：

| 最小间隔 | 等效最大有效频率 |
| --- | --- |
| `100 us` | `10000 Hz` |
| `1000 us` | `1000 Hz` |
| `100000 us` | `10 Hz` |

页面文案必须说明：小于该间隔的原始边沿会保留在脉冲明细中，但不会计入有效脉冲。

### RAM 最近明细

RAM 固定保留最近 1 条完整原始脉冲明细，用于刚结束的出水查看、实测容量录入和写入会话样本区或长期样本库。重启后 RAM 明细丢失。

## 固定容量

- 单条最大原始边沿数：`4096`。
- 校准会话样本区容量：`3` 条，可在新会话开始时清空并覆盖。
- 长期校准样本库容量：`5` 条，不自动覆盖。
- 长期样本库满时拒绝新保存，只提示用户清理或放弃，不自动覆盖最旧样本。

长期校准样本库容量固定为 5 条，不自动覆盖；本次会话样本区固定为 3 条，可在新会话开始时覆盖。

容量估算：

```text
单条最大边沿数据：4096 * 4 = 16384 bytes，约 16 KiB
会话样本区 3 条：3 * 16 KiB = 48 KiB
长期样本库 5 条：5 * 16 KiB = 80 KiB
加上头部、索引、暂停时间窗、状态和校验后，新样本文件预算约 130-150 KiB
RAM 最近 1 条：1 * 16 KiB = 16 KiB，加头部后仍可控
```

如果单次出水期间原始边沿数超过 `4096`，明细标记为截断。截断记录仍可用于查看，但不可参与启动阶段和分段计量校准分析。

## 文件格式

Flash 存储收敛后，生产固件不再接入独立“已保存脉冲明细”文件。完整样本只写入当前校准会话样本区和长期样本库：

```text
/faucet_cal_session_traces_v1.bin
/faucet_cal_samples_v1.bin
```

生产固件不读取其他脉冲明细文件。遇到当前样本文件版本、记录大小或校验不匹配时，store 返回不可用或损坏状态，由测试阶段人工格式化或重建。

保存格式建议使用固定槽位：

- 校准会话样本区槽位数量固定为 3。
- 长期样本库槽位数量固定为 5。
- 每个槽保存一条明细头、暂停时间窗和最多 4096 个 `elapsedUs`。
- 删除明细只清空对应槽位索引。
- 保存满时返回容量满状态，不自动覆盖。

固定槽位比变长文件更简单可靠，偏移明确，删除和读取逻辑可预测；在 3 条会话样本和 5 条长期样本容量下空间预算可控。

## 保存策略

- 每次本地出水结束后，RAM 中保留最近原始明细。
- 校准会话中的候选样本先写入会话样本区；保存实测容量后成为本次会话有效样本。
- 新会话开始时清空并覆盖会话样本区，不影响长期样本库。
- 用户确认应用或显式保存后，合格样本进入长期样本库；长期样本库满时必须提示用户处理，不自动覆盖。
- 已保存长期样本可由用户手动删除。

## 暂停和样本有效性

脉冲明细保存事实，不因为样本不可参与分析而丢弃。

启动阶段和分段计量样本有效性规则：

- 未暂停，完成或手动停止：可参与分析。
- 暂停后未恢复出水，最终手动停止或暂停超时：可参与分析。
- 暂停后恢复出水：可以查看明细，但不可参与启动阶段和分段校准分析，因为它包含多次启动过程。
- 明细截断：不可参与分析。
- 无实测容量：不可参与拟合。
- 异常错误结果：不可参与拟合，除非后续明确扩展某类异常的分析价值。

页面必须直接展示不可参与分析的原因，例如“多段出水，不参与样本拟合”或“明细已截断”。

## 接水记录详情页

记录列表中每条记录都应提供“详情”操作。接水记录详情页面向普通用户，展示一次接水的完整业务信息，不等同于脉冲明细。

详情页应展示：

- 开始时间、结束时间、持续时间。
- 模式、目标、固件估算出水量。
- 实测出水量和是否已校准。
- 结果：完成、手动停止、暂停超时、异常等。
- 有效脉冲数、过滤边沿数、原始边沿数。
- 当时使用的计量方案 ID、名称和状态；需要展开时再查看方案记录。
- 当时使用的 `pulseMinIntervalUs` 和等效最大有效频率。
- 暂停情况和出水段数量。
- 是否有脉冲明细、是否可参与样本分析、是否已进入长期样本库。
- 操作入口：校准或重校、查看脉冲明细、长期样本入库或移除。

详情页只展示用户需要理解的汇总信息。底层边沿列表、过滤判定明细和专业图表放在脉冲明细页。

## 脉冲明细页

脉冲明细页面向调试、校准和设备排查。

展示原则：

- 有效脉冲是主信息。
- 原始边沿是辅助信息，用更淡、更轻的视觉层展示。
- 被过滤边沿必须可见，但不应喧宾夺主。

趋势图建议：

- 主线或主柱：有效脉冲按窗口统计。
- 辅助淡色线或背景柱：原始边沿按同一窗口统计。
- 过滤边沿：淡色点或短竖线。
- 暂停时间窗：淡色背景区间，并使用虚线边界标出暂停开始和结束。

明细表建议：

- 默认展示有效脉冲明细。
- 提供“显示全部原始边沿”。
- 全部原始边沿中，过滤边沿使用淡色行。
- 每行可展示 `elapsedUs`、距上个原始边沿间隔、距上个有效脉冲间隔、判定结果、累计有效脉冲。

分析结果旁必须展示使用的判定规则，例如“按本条记录的最小有效间隔 1000 us 判定”。后续如果提供按当前配置重新分析的功能，必须明确区分“本条记录配置”和“当前配置”。

## 专业评估

本设计把原始事实和分析结果分离，是比按秒保存脉冲数更可靠的方案。

优点：

- 避免秒边界导致的 `7/9` 这类分桶误差被误认为原始事实。
- 可以区分真实高频脉冲、硬件噪声和软件过滤结果。
- 分析算法变化后，可基于同一份原始边沿重新计算。
- 用户记录详情和专业脉冲明细定位清晰。
- RAM、会话样本区和长期样本库容量在当前 ESP32/LittleFS 资源下可控。

风险和约束：

- ISR 必须短小，只记录时间或推入环形缓冲，不做文件写入、日志或复杂计算。
- 主循环必须及时 drain ISR 缓冲；如果缓冲溢出，必须记录丢弃计数并标记明细不完整。
- 原始边沿数量可能因硬件噪声暴增，超过 4096 时必须截断并禁止参与校准。
- 实时出水控制仍必须按有效脉冲计量，不能让原始噪声边沿直接影响停水。
- 每条明细必须保存当时的有效脉冲判定配置和计量方案引用，否则旧记录会被新配置重新解释而产生混乱。

## 最终结论

脉冲明细以原始边沿 `elapsedUs[]` 和暂停时间窗 `pauseWindows[]` 作为事实源。有效脉冲、过滤边沿、每秒统计、稳态识别和分段校准都是派生结果。系统配置只控制有效判定和 RAM 保留数量，不暴露底层存储格式。校准会话样本区固定 3 条，长期样本库固定 5 条，长期样本保存满拒绝新保存。暂停后恢复出水的记录保存但不参与启动阶段和分段校准分析。

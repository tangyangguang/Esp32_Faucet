# 脉冲分段计量参数说明

本文是“脉冲分段计量参数”和“流量计计量方案”的用户说明，用来统一页面概念、参数含义和校准流程。它只描述用户需要理解和操作的内容，不描述代码实施步骤。

## 设计边界

旧的“控制 P/L、启动补偿、启动等效”等概念不再作为页面概念、文档概念或代码设计概念保留。

新的计量模型把流量计计量方案参数分成两组：

- 容量估算计量参数：根据流量计脉冲估算实际出水容量。
- 时间估算计量参数：根据目标容量估算预计出水时间和预计稳态流速。

这些字段都保存在“流量计计量方案”中。方案和具体流量计、水路、水压、滤芯状态、安装环境有关，可以保存多套用于实验、对比、回滚和不同场景切换。

## 要解决的问题

当前设备用单一 P/L 系数估算出水量。大容量出水时，这个系数通常比较稳定；但小容量出水时，开阀初期的水流爬坡会占比较大，容易出现偏差。

新的计量模型把一次出水分成两段：

- 启动段：开阀后的前几个脉冲，水流还没有完全稳定。
- 稳态段：水流稳定后的脉冲，按稳定 P/L 计算。

这样做的目标是让小容量和大容量都能用同一套参数解释，而不是用一个全程平均 P/L 去硬套所有容量。

## 核心概念

### 流量计计量方案

流量计计量方案是一套可保存、可启用的水量换算参数。系统不把固定数量上限作为用户概念，页面按动态列表展示已有方案。

系统内置一套 `YF-S201 默认计量方案`，用于保证设备首次启动或默认方案缺失时仍能计量。内置参数为启动脉冲数 8P、启动水量 36ml、稳态 225P/L、启动时长 5000ms、预计稳态流速 480ml/min；创建说明会记录这是基于 YF-S201、启动阶段约 5 秒、前 5 秒约 8 个脉冲的默认参数。

每套方案有 5 个计量参数：

容量估算计量参数：

- 启动脉冲数：启动段包含多少个脉冲。
- 启动水量：启动段这些脉冲对应多少 ml 水。
- 稳态 P/L：进入稳定流量后，每升水对应多少个脉冲。

时间估算计量参数：

- 启动时长：启动段预计持续多少 ms。
- 预计稳态流速：进入稳态后的预计流速，单位 ml/min。

容量估算计量参数用于实际容量、滤芯累计和统计累计。时间估算计量参数只用于预计时间和预计稳态流速展示，不参与实际出水容量、滤芯累计或统计累计。除这 5 个字段以外，生成方案时用到的样本数量、容量范围、最大误差、启动阶段时长统计等信息，都作为创建依据保存，后续修改方案时不改变这些创建依据。

### 当前计量方案

当前计量方案是设备正在用于出水估算的方案。只有显式执行“启用方案”后，设备才切换当前计量方案。

### 计量方案生成结果

计量方案生成结果是根据当前已保存样本生成出来的结果。生成结果不会自动保存为正式方案，也不会自动启用。

生成结果确认后只能保存为新方案。保存新方案后仍不会自动启用，需要用户再显式启用。

### 启动阶段时长统计

启动阶段时长统计表示生成方案时，样本中观察到“进入稳态大概需要多久”。它是创建依据快照，用于判断样本质量。它不同于计量方案里的 `startupDurationMs`；后者是时间估算计量参数，用于预计展示。

页面可以显示为：

```text
启动阶段时长：中位 5s，平均 5.4s，范围 3-8s
```

如果平均值明显偏离中位数，或范围很散，例如 2-15s，说明启动过程波动大，这套方案需要谨慎启用。

### 全程平均 P/L

全程平均 P/L 不能作为独立系统参数，因为它会随出水量变化。

它只能出现在有明确水量上下文的位置：

- 历史记录：本次总脉冲和本次实测水量对应的全程平均。
- 容量预设：当前计量方案下，某个目标容量预计会表现出来的等效全程平均。

页面不应单独显示一个没有上下文的“全程平均 P/L”。

## 计量逻辑

设：

```text
P  = 当前累计有效脉冲数
Ns = 启动脉冲数
Vs = 启动水量，单位 ml
Ps = 稳态 P/L
V  = 估算出水量，单位 ml
```

计量公式为：

```text
P = 0:
  V = 0

0 < P <= Ns:
  V = round(P * Vs / Ns)

P > Ns:
  V = Vs + round((P - Ns) * 1000 / Ps)
```

含义是：前 `Ns` 个脉冲按启动段估算，超过 `Ns` 后按稳态 P/L 估算。

`Ns = 0` 且 `Vs = 0` 时，启动段等价于没有，全部有效脉冲按稳态 P/L 计算。

实际容量始终使用上述容量估算公式。时间估算计量参数不能用于补算实际出水容量；异常或 0 脉冲时不能假设已经出水。

## 时间估算逻辑

设：

```text
V  = 目标容量或预计容量，单位 ml
T  = 预计时间，单位 ms
Vs = 启动水量，单位 ml
Ts = 启动时长，单位 ms
Fs = 预计稳态流速，单位 ml/min
```

目标容量预计时间：

```text
Ts = 0 或 Vs = 0:
  T = V * 60000 / Fs

V <= Vs:
  T = V * Ts / Vs

V > Vs:
  T = Ts + (V - Vs) * 60000 / Fs
```

给定时间预计容量：

```text
Ts = 0 或 Vs = 0:
  V = T * Fs / 60000

T <= Ts:
  V = T * Vs / Ts

T > Ts:
  V = Vs + (T - Ts) * Fs / 60000
```

时间估算只用于预设、确认页等位置的辅助展示。

## 流速概念

页面和文档必须区分 3 种流速：

- 实时流速：出水过程中用最近脉冲时间窗口计算，用于运行页实时显示和流量异常判断。
- 预计流速：计量方案中的预计稳态流速，用于预设和确认页展示。
- 平均流速：出水结束后用实际记录容量除以实际出水时长计算，用于历史记录和统计展示。

## 参数从哪里来

参数可以来自两种方式：

1. 根据样本生成结果。
2. 手工新建计量方案。

一个样本要参与生成方案，需要同时满足：

- 有脉冲明细。
- 已校准量杯实测水量。
- 原始边沿未因超过单条上限而被截断。
- 未发生暂停后恢复出水。
- 能识别出稳定流量段。
- 已保存到设备样本库。
- 有效样本不少于 2 条。
- 样本容量覆盖小容量和大容量，最大实测水量和最小实测水量差值不少于 500ml。
- 拟合后的最大绝对误差不超过 100ml，最大相对误差不超过 5%。

RAM 临时明细只用于查看和校准入口，不能直接参与生成。用户在样本列表中校准 RAM 明细容量时，系统必须先把该明细写入设备样本库；入库失败时本次校准失败。

如果有效样本数量、容量覆盖、稳定性或误差结果不满足生成要求，页面只显示诊断原因，不生成可保存的生成结果。

## 方案数据

每套流量计计量方案保存：

- 方案名称。
- 流量计标识、水路或安装位置、环境标签和备注。
- 启动脉冲数。
- 启动水量。
- 稳态 P/L。
- 启动时长。
- 预计稳态流速。
- 创建来源：样本生成、手工创建或系统默认。
- 当前状态：可用或停用。
- 修订号。
- 创建时间。
- 最近修改时间。
- 最近启用时间。
- 已使用状态。
- 样本数量。
- 参与生成的样本明细 ID 摘要。
- 样本实测水量范围。
- 最大误差。
- 最大相对误差。
- 启动阶段最小时长。
- 启动阶段最大时长。
- 启动阶段中位时长。
- 启动阶段平均时长。
- 创建说明。
- 最近修改说明。

样本数量、容量范围、最大误差和启动阶段时长统计是创建时的样本依据快照。后续修改方案时，这些创建依据不变，只更新最近修改信息。

手工新建方案没有样本依据，创建来源记录为“手工创建”。

## 操作流程

推荐流程：

1. 按常规方式本地出水。
2. 在校准页样本列表中选择有脉冲明细的记录，校准量杯实测容量。
3. 校准成功后确认样本已写入设备样本库。
4. 查看脉冲明细，确认样本质量。
5. 积累多个容量的有效样本。
6. 手动生成结果。
7. 检查生成结果的 5 个计量参数、样本数量、容量范围、误差和启动阶段时长统计。
8. 如果结果合理，保存为新方案。
9. 需要实际使用时，再显式启用该方案。
10. 再用不同容量复测。

## 操作规则

- 生成结果：只产生待保存结果，不保存正式方案，不影响当前出水。
- 保存为新方案：只能创建新方案，不能覆盖已有方案，不能覆盖当前方案，不自动启用。
- 新建计量方案：手工填写名称和 5 个计量参数，不自动启用。
- 修改计量方案：可修改名称和 5 个计量参数；如果修改当前方案，保存后立即影响后续估算，页面必须明确提示。
- 启用方案：显式切换当前计量方案。
- 停用方案：只允许停用非当前方案；停用后不作为日常启用选择，但仍可查看和恢复。
- 删除方案：只允许删除从未被出水记录使用过、非当前方案、且删除后仍至少保留一套有效方案的方案；已经使用过的方案不能删除，只能停用。

当前计量方案必须始终存在。当前方案不能停用，也不能删除；如果系统只剩最后一套有效方案，也不能删除。

每条出水记录保存当时的方案 ID，不保存 5 个计量参数快照。用户不能手动删除已被记录引用的方案；影响计量的修改创建新方案 ID 或新的不可变版本。方案槽位满后系统可覆盖最早的非当前方案，历史记录查不到方案时显示已覆盖。

方案修订号只作为方案自身的辅助字段。对从未使用过的方案，可以直接修改 5 个计量参数；对已经被出水记录使用过的方案，任何影响计量的修改都必须创建新的方案 ID 或新的不可变版本。只修改名称、停用状态等不影响计量的字段，可以在原方案上更新。

方案使用状态只在出水记录成功写入后从“未使用”变为“已使用”。使用状态不因历史记录环形覆盖而回退；状态更新失败时按已使用方案处理：不能由用户手动删除，只能停用。

## 推荐页面结构

校准页建议按用户任务分成 5 块：

1. 当前计量方案
   - 显示当前启用方案名称。
   - 显示容量估算计量参数和时间估算计量参数。
   - 明确提示时间估算计量参数只用于预计展示，不参与实际容量、滤芯累计或统计累计。
   - 显示创建来源、样本依据和最近修改。

2. 计量方案生成
   - 显示样本覆盖：长期样本、已校准容量、可生成样本、容量范围、拟合误差和还需补充的条件。
   - 提供“生成生成结果”操作。
   - 明确提示生成不会保存正式方案，也不会启用。

3. 计量方案生成结果
   - 显示根据当前样本生成的新方案。
   - 明确提示“生成后不会自动保存或启用”。
   - 提供“保存为新方案”和“放弃生成结果”。

4. 流量计计量方案
   - 显示已有方案动态列表。
   - 每套方案显示“未使用过”或“已使用”。
   - 可用方案可以查看、启用、修改或停用。
   - 未使用过、非当前且不是最后一套有效方案的方案可以删除。
   - 停用方案默认折叠，可恢复为可用。
   - 当前方案有明确标记。

5. 新建计量方案
   - 支持手工输入名称、启动脉冲数、启动水量、稳态 P/L、启动时长和预计稳态流速。
   - 新建后不自动启用。

6. 样本区
   - 显示 RAM 临时样本和已保存样本。
   - 显示容量是否已校准、稳态是否识别成功、是否可参与生成。
   - 支持校准容量、查看明细，以及在明细页保存或删除样本。

## 页面文案原则

- 不再使用旧概念，例如“控制 P/L”“启动补偿”“启动等效”。
- 页面优先使用“当前计量方案”“计量方案生成结果”“流量计计量方案”“启动脉冲数”“启动水量”“稳态 P/L”。
- 所有会改变当前计量行为的动作，都要明确显示结果，例如“启用此方案”。
- 生成结果要明确提示“不保存、不启用”。
- 保存生成结果必须写成“保存为新方案”。
- 保存为新方案要明确提示“不自动启用”。
- 全程平均 P/L 只跟具体记录或具体预设一起显示。
- 页面必须分组显示“容量估算计量参数”和“时间估算计量参数”。
- 页面必须明确“时间估算计量参数只用于预计展示，不参与实际容量、滤芯累计或统计累计”。
- “实时流速”“预计流速”“平均流速”必须区分显示，不混用。

## 后续实现约束

后续代码实现应以新模型为唯一运行时计量模型：

- 出水计量不再使用“单一 P/L + 启动补偿”。
- 配置中不再保存“控制 P/L、启动补偿、启动等效”这些独立概念。
- 流量计计量方案应独立于系统业务配置持久化，保存当前方案、生成结果和动态方案记录。
- 新设备首次启动时应创建系统内置 `YF-S201 默认计量方案`，作为可用兜底参数。
- 方案中 5 个计量参数是结构化计量字段；样本统计、启动阶段时长范围、中位数、平均数和误差等作为创建依据保存。
- 已经被出水记录使用过的方案不允许物理删除，只允许停用。
- 出水记录必须保存计量方案 ID；不得为了历史追溯重复保存完整计量参数快照。
- 页面、API 和测试用例都应使用新概念命名。

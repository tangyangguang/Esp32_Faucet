# 脉冲分段计量

本页是分段计量的工程说明，最终规则以 `docs/脉冲分段计量参数说明.md` 和 `docs/10-flow-meter-metering-schemes.md` 为准。

## 运行时参数

运行时只使用当前流量计计量方案中的 3 个核心字段：

- 启动脉冲数 `Ns`
- 启动水量 `Vs`
- 稳态 P/L `Ps`

系统最多保存 10 套流量计计量方案。页面按动态列表显示已有方案，不显示固定空位。每套方案都绑定具体流量计、水路和水压环境下的计量假设。

## 计量公式

设本次有效脉冲数为 `P`：

- `P = 0`：估算水量为 `0`
- `0 < P <= Ns`：估算水量为 `round(P * Vs / Ns)`
- `P > Ns`：估算水量为 `Vs + round((P - Ns) * 1000 / Ps)`

`Ns = 0` 且 `Vs = 0` 时，启动段等价于没有，全部有效脉冲按稳态 P/L 计算。

## 候选计量方案

校准页从已保存到设备、容量已确认且稳态识别成功的样本生成候选计量方案。候选不会直接启用，也不会直接进入方案列表。

候选确认后只能保存为新方案：

- 保存为新方案：创建一套新的流量计计量方案，不自动启用。
- 丢弃候选：清除候选，不改变已有方案。

候选不能覆盖已有方案，不能覆盖当前启用方案，也不能直接启用。

## 流量计计量方案

每套方案保存：

- 方案名称。
- 3 个核心计量参数。
- 创建来源：样本生成、手工创建、迁移或默认。
- 创建时的样本依据：样本数量、容量范围、最大误差、启动阶段最小/最大/中位/平均时长。
- 最近修改信息。
- 最近启用时间。

样本依据是创建时快照，后续修改方案不会改变这些创建依据。手工创建方案没有样本依据，只记录“手工创建”。

## 操作边界

- 生成候选计量方案：只产生候选，不影响当前出水。
- 保存为新方案：只新增方案，不启用。
- 新建计量方案：手工填写名称和 3 个核心参数，不启用。
- 修改计量方案：可修改名称和 3 个核心参数；如果修改当前启用方案，保存后立即影响计量，页面必须明确提示。
- 启用方案：显式切换当前计量方案。
- 删除方案：只允许删除非当前启用方案，系统必须始终保留至少一套有效方案。

## 持久化与迁移

流量计计量方案使用独立持久化域管理，不应跟安全阈值、显示、蜂鸣器、预设和滤芯等系统配置一起整块重写。

升级迁移时：

- 旧当前计量配置迁移为当前流量计计量方案。
- 旧的非默认有效配置迁移为独立方案。
- 旧候选迁移为候选计量方案。
- 迁移后不再读写旧字段。

固件升级不得静默清空可识别的用户计量方案。

## 页面边界

Web 只提供容量确认、样本查看、候选生成、保存为新方案、新建方案、修改方案、启用方案、删除非当前方案和查看记录能力，不提供任何远程出水控制能力。

历史记录、容量预设等有明确水量上下文的位置可以显示对应 P/L 诊断值；没有水量上下文的独立平均值不得作为系统参数显示或保存。

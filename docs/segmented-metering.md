# 分段计量诊断与自动校准

## 背景

当前流量计在大容量接水时表现稳定，例如 7.5L 记录可得到约 221P/L 的全程平均值；但同一系数用于 1.0L、1.5L 等小容量时会明显多出水。现场观察显示启动阶段存在爬坡：开阀后先有短暂停顿，随后小流量出水，几秒后才进入稳定流量。关阀阶段水和传感器都能快速停止，第一版不做尾段补偿。

因此单一 `pulsePerMl` 只能描述全程平均，不足以解释小容量误差。项目采用“分段计量”作为长期诊断和校准模型。

## 模型

总出水量 = 启动阶段出水量 + 稳态阶段出水量。

- 启动阶段：使用固定时长、固定脉冲数和反推水量描述，不直接套用稳态 P/L。
- 稳态阶段：使用稳定后的 `stablePulsePerLiter` 计算。
- 全程平均：保留 `overallPulsePerLiter`，用于和历史 7.5L 实验数据比对。

第一版只保存和展示分段参数，不改变关阀控制。确认数据稳定后，再单独启用“分段计量参与控制”。

## 脉冲明细采样

每次出水在 RAM 中按 1 秒记录全程脉冲明细：

- 本秒新增脉冲数。
- 本秒状态：`running`、`paused`、`completed`、`stopped`、`error`。

不保存秒序号、累计脉冲和估算水量；详情页实时计算这些派生值，以节省 RAM 并避免把当前估算逻辑固化进历史样本。

脉冲明细只保存在 RAM，不写入 Flash。系统配置 `pulseTraceMemoryKb` 控制 RAM 上限，默认 50KB，可配置范围 10-50KB。超限后删除最旧明细，尽量保留更多最近接水数据。

## 页面展示

记录页顶部显示当前计量参数：

- 全程平均 P/L。
- 启动段：时长、脉冲、水量。启动段不是线性稳定区间，不对外展示 P/L。
- 稳态段 P/L。
- 分段计量状态：诊断中或已校准。

记录页顶部同时显示脉冲明细缓存：

- 明细条数。
- 数据点数。
- 当前占用和上限。
- 上限能力：约可保存的数据点数和最多明细条数。
- 使用率进度条。
- 最早和最新明细时间。

记录表在“脉冲”列显示“明细”标识。有 RAM 脉冲明细时显示“明细”，点击进入详情页；明细被缓存淘汰后不显示入口。

详情页支持 1s、2s、3s、5s 聚合查看：

- 每桶脉冲折线图。
- 累计脉冲数据。
- 原始秒级明细默认展示 `0秒` 到 `30秒`，包含第 30 秒；超过 30 秒的明细通过“显示所有明细”打开完整文本。
- 自动识别的稳态开始秒。
- 本条明细占用、样本数、总脉冲和持续时间。
- 输入实测容量并保存为分段样本。

## 稳态识别

第一版算法只分析 `running` 秒，暂停秒展示但不参与判断。

算法步骤：

1. 取后半段 running 样本估计稳定脉冲/秒。
2. 从前向后寻找连续窗口，要求窗口首秒达到稳定脉冲水平。
3. 窗口平均值接近后半段稳定值，且窗口内波动受限。
4. 找到后输出：
   - `stableStartSec`
   - `startupPulseCount`
   - `stablePulseCount`
   - `stablePulsePerSec`
   - `confidence`

如果明细太短、后半段无有效脉冲或波动过大，显示“无法识别”。

## 自动校准

每条脉冲明细详情页可输入实测容量。保存后，该明细成为分段校准样本。自动校准默认使用最近有效样本，也可在详情页手动勾选历史样本。

至少需要两条有效样本，且容量差异明显。计算方式：

1. 选择最小实测容量样本和最大实测容量样本。
2. 用两条样本的稳态脉冲差和实测水量差计算 `stablePulsePerLiter`。
3. 用小容量样本反推启动段水量。
4. 用大容量样本计算 `overallPulsePerLiter`，作为全程平均参考。

保存后的长期配置：

- `overallPulsePerLiter`
- `startupDurationSec`
- `startupPulseCount`
- `startupVolumeMl`
- `stablePulsePerLiter`
- `segmentedMeteringCalibrated`

## 上板实验流程

1. 保持当前单一系数控制，不启用分段控制。
2. 依次测试 1.0L、1.5L、2.0L、3.0L、7.5L，每个容量至少 5 次。
3. 每次记录实际水量，并在脉冲明细详情页保存。
4. 查看 1s、3s、5s 聚合图，确认启动爬坡和稳态开始秒是否一致。
5. 自动校准后对比：
   - 全程平均 P/L 是否接近 7.5L 历史约 221P/L。
   - 稳态 P/L 是否在多次实验中稳定。
   - 启动段水量是否能解释小容量多出水。
6. 当多容量、多次实验误差稳定后，再评估是否启用分段计量参与关阀控制。

## 限制

- RAM 脉冲明细重启后消失，不用于长期审计。
- 第一版稳态识别是启发式算法，低脉冲频率下建议优先查看 3s 或 5s 聚合图。
- 自动校准依赖用户输入的实测容量；量杯读数误差会直接影响结果。
- 第一版不处理关水尾段，因为现场验证水阀和传感器停止干脆。

# UI 与交互草案

## 当前已确认原则

- 本地输入使用三个功能按键：`STOP`、`OK`、`NEXT`。
- 不使用颜色命名按键。
- 本地交互优先支持高频操作和软件停止兜底。
- 复杂配置优先放到 Web，避免三键本地菜单过重。

## 按键语义

- `STOP`：停止、关阀、取消、返回，软件停止优先级最高。
- `OK`：确认、启动、暂停/继续。
- `NEXT`：切换预设、切换菜单项、调整枚举值。
- `STOP + OK` 长按：恢复出厂设置。

## 状态交互

### 待机

- `NEXT` 短按：在启用预设之间循环切换。
- `OK` 短按：进入当前预设的二次确认。
- `NEXT` 长按：进入本地简易菜单。
- `STOP` 短按：确保关阀并保持待机，不记录出水日志。

### 二次确认

- `OK` 短按：开始出水。
- `STOP` 短按：取消并返回待机。
- `NEXT` 短按：切换到下一个预设。
- 10 秒无操作：自动取消。

### 出水中

- `STOP` 按下瞬间：立即关阀，返回待机或错误提示，优先级最高。
- `OK` 短按：暂停。
- `NEXT` 短按：无动作，只给无效提示，避免运行中误切预设。

### 暂停

- `OK` 短按：继续出水。
- `STOP` 短按：停止任务并返回待机。
- 超过暂停超时时间：自动停止并记录暂停超时。

### 本地简易菜单

- `NEXT` 短按：切换菜单项。
- `OK` 短按：进入或确认。
- `STOP` 短按：返回上一级。
- `STOP` 长按：退出菜单回到待机。

当前编码已完成的本地特殊操作：

- 长按 `OK`：进入流量校准。
- 校准选择页：`NEXT` 切换 500/1000/1500/2000ml，`OK` 进入二次确认，`STOP` 退出。
- 校准确认页：`OK` 开阀开始采样，`STOP` 放弃。
- 校准采样中：水到容器刻度后按 `OK` 关阀并记录样本，`STOP` 放弃。
- 校准保存页：至少两次样本一致后显示旧系数和新系数，`OK` 保存，`STOP` 放弃。
- `STOP + OK` 长按：进入恢复出厂二次确认页，`OK` 确认执行，`STOP` 取消。

本地菜单不修改预设值。预设、滤芯、WiFi、OTA 等复杂操作放 Web。

## OLED 页面草案

| 页面 | 第一行 | 第二行 |
| --- | --- | --- |
| 待机 | 当前预设值 | 今日/总累计、网络状态轮播 |
| 确认 | `OK Start?` | 预设名称和值、倒计时 |
| 运行 | 剩余量或剩余时间 | 已出水量、当前流量 |
| 暂停 | `Paused` | 自动停止倒计时 |
| 错误 | 错误代码 | 简短原因 |
| 网络 | IP 或配网状态 | hostname |
| 校准 | 目标容量/采样次数 | 旧系数、新系数、确认保存提示 |

OLED 文案优先使用短英文和数字，避免 128x32 屏幕中文过宽导致拥挤。

## Web 页面草案

- 首页：当前状态、当前预设、基础统计。
- 配置：预设、阈值、蜂鸣器、显示、安全参数。
- 日志：分页查询。
- 统计：今日、本周、本月、总累计。
- 滤芯：最多 6 个滤芯的已用天数、已用流量、寿命设置、独立设置入口和重置入口。
- 校准：查看当前流量系数，支持手动录入系数；不允许远程启动校准出水。
- OTA：使用 Esp32Base 内置页面。

Web 页面不得提供启动出水、暂停出水、继续出水或停止出水入口。

### Web 滤芯交互

- 滤芯页只显示列表，便于快速查看每级滤芯状态、已用天数、已用流量和寿命设置。
- 每级滤芯提供“设置”入口，进入独立编辑页后再修改启用状态、名称、寿命天数、寿命流量、上次更换日期。
- 寿命流量以 ml 输入，并在输入框下方显示 L，页面展示默认使用 L 且保留 2 位小数。
- 上次更换日期使用浏览器日期选择控件，提交值仍按 `YYYY-MM-DD` 校验；有效日期范围为 2020-2099，保存后作为已用天数的起点。
- 保存或取消后返回滤芯列表页，避免低频配置表单占用列表页空间。
- 重置需要二次确认，提交后清零该级滤芯累计流量、更新更换时间，并返回滤芯列表页。

## 本地流量校准交互

- 进入校准页后，`NEXT` 选择目标容量：500ml、1000ml、1500ml、2000ml。
- `OK` 开始校准出水。
- 水到达目标刻度时，按 `OK` 停止本次采样。
- `STOP` 任意时刻取消校准并关阀。
- 至少完成 2 次有效采样且偏差不超过 5% 后，显示新旧系数。
- 确认页按 `OK` 保存新系数，按 `STOP` 放弃。

## 恢复出厂确认

- `STOP + OK` 长按只进入恢复出厂确认页，不立即执行清除。
- 确认页显示恢复出厂风险提示。
- 在确认页按 `OK` 执行恢复出厂；按 `STOP` 取消。
- 10 秒无操作自动取消。

## 已确认事项

- 本地菜单不允许修改当前预设值。
- 出水中 `OK` 短按用于暂停，`STOP` 用于停止。
- Web 端不允许任何出水控制。
